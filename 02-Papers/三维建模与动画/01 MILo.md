### 1.1 论文要回答什么

**问题：** 从同一场景的多视角照片中，重建既能渲染、又有可用表面的三维场景。官方示例采用 COLMAP 场景输入，包含图像、相机信息和初始化点云（`scene/__init__.py:43–44,80–82`）。

3DGS 用许多带位置、大小、方向、透明度和颜色的高斯描述场景；三角网格则明确给出顶点及三角面连接关系。<mark>图像拟合好，并不自动等于表面几何准确。</mark>

### 1.2 现有方法哪里不足

FACT：作者在引言指出，先优化体表示、结束后才提取表面的做法缺少来自最终网格的训练反馈；细小结构可能在提取时消失，网格可能出现漂浮碎片、空洞或过多顶点（PDF 2–3）。这是作者对其讨论方法的概括，不扩成所有三维方法均如此。

具体例子：自行车辐条在渲染图中可见，不代表转换为三角网格后仍有正确、连续的细杆几何。后续编辑、碰撞或形变需要几何本身，不能仅凭一张好看的图像判断。

作者的核心想法：在网格参与优化的阶段，每轮从高斯生成网格，比较两种表示的深度/法线，并把误差反馈给表示参数，促进几何一致性（§3、§5）。这里先建立闭环直觉，不把三角化的离散连接关系误说成连续可微。

图 1：左侧是自行车场景，右侧是雕像及背景；每边上方将灰色网格与彩色渲染拼接显示，下方给出局部对照。左下对比 MILo 与 RaDe-GS 的网格，右下对比 MILo 与 GOF 的雕像细节。它同时展示场景覆盖、局部几何与作者标注的个案指标，不能单独证明所有场景均提升相同比例。

## 2. 核心概念与术语

| 概念 | 本站的最小解释 |
|---|---|
| 3D Gaussian Splatting | 用许多可调的三维高斯表示场景，并投影、混合成图像 |
| Mesh | 顶点和三角面组成的显式表面；便于按几何进行编辑、形变与碰撞处理 |
| In-the-loop | 结果在优化过程中被计算并提供反馈；本论文指网格参与高斯优化 |

| Gaussian Pivots | 从被选高斯的中心和包围盒角点生成的空间支点；一个高斯提供9个点，支点不等于最终网格顶点 |
| Delaunay tetrahedralization | 把三维支点构成的空间划分为四面体；这里只在更新时计算离散连接关系，不对连接选择求连续梯度 |
| 可学习的SDF值 | 每个支点附带一个带符号标量，过零位置定义表面；作者明确说明它们并不来自严格的真实距离场 |
| Marching Tetrahedra | 检查四面体边上是否出现异号值，在异号边上插值得到表面交点，再组成三角面 |
| 深度图 / 法线图 | 每个像素处的表面距离 / 朝向。MILo比较高斯与网格渲染出的这两类几何信息 |
| 体—表一致性 | 让高斯体表示与提取出的网格表面在同一视角下给出一致的几何信号 |

名称中的“可微提取”要落到具体路径：<mark>表面位置对支点位置及符号值可微，不等于离散三角化的每个连接选择都可微。</mark>

## 3. 论文贡献与方法主线

### 3.1 输入、变量与控制条件

输入是同一静态场景的多视角RGB观测、相机标定信息和初始化点云。每个场景分别优化自己的高斯参数及附加SDF参数；这与训练一个能直接泛化到所有新场景的大型生成模型不同。

被优化的量包括高斯中心、尺度、旋转、透明度、外观参数，以及高斯支点对应的符号值。用于三角化的高斯子集由重要性采样选出；相机、观测图像和基准真值不作为该环节随意改变的变量。

### 3.2 方法或系统结构

![[MILo-fig02-体表一致性优化流程.png]]

Figure 2（PDF第4页）从左向右读：左上是唯一的可学习高斯表示，向右渲染RGB、深度和法线；左下是从表示导出的网格，也向右渲染深度和法线。右上真实图像约束外观，中下两组几何输出相互比较；橙色方向表示反向传播。网格不是一份完全独立、另外任意移动的顶点参数表。

在网格参与优化的阶段，一次循环可拆成五步：

1. 由选中高斯的中心、尺度与旋转生成支点。
2. 获取当前支点的Delaunay四面体连接；到更新轮次才重算连接。
3. 取得各支点的可学习SDF值。
4. 在异号边上用Marching Tetrahedra插值，得到三角网格。
5. 渲染高斯和网格，计算图像、体表一致性及正则损失，再把梯度传回表示参数。

![[MILo-fig03-高斯支点与表面交点.png]]

Figure 3（PDF第5页）是二维示意：有色椭圆代表两个高斯；黑方块是支点，虚线是三角化连接，红蓝符号值的变化决定哪里穿过表面；粗黑线及其黑色交点表示提取出的表面。**黑方块与黑圆点承担不同角色**，不能把全部支点直接当作最终网格顶点。

| 组件 | 输入→输出 | 是否学习 | 为什么需要 |
|---|---|---|---|
| 高斯表示 | 参数→图像/深度/法线 | 是 | 保留高效且有表达力的场景表示 |
| 重要性采样 | 多视角贡献→高斯子集 | 选择过程本身不求梯度 | 限制几何提取成本 |
| 支点生成 | 中心/尺度/旋转→9个支点 | 对高斯参数可微 | 同时采到表面附近及两侧的位置 |
| 四面体化 | 支点→整数连接 | 离散计算 | 提供局部表面插值的空间单元 |
| SDF参数与表面提取 | 符号值/支点/连接→网格 | 对符号值和支点可微 | 精细控制过零表面，而非仅按高斯透明度切面 |
| 网格渲染及正则 | 网格与观测→损失 | 梯度回到表示 | 让表面质量实际影响优化 |

Base与Dense区别：Base只保留采样出的重要高斯，得到较轻表示；Dense保留较多高斯用于渲染，但仍只用采样子集产生支点。不能把“高斯总数”“选中高斯数”“支点数”和“网格顶点数”混为一谈。原文§4.1给出Base约0.1–0.5M高斯，Dense描述约2–5M；§6.1另以2–4M概括其典型Dense实验，范围受场景影响，不合并成一个精确常量。

### 3.3 数据生成、筛选与标签质量

一条观测可以理解为“某台已标定相机看到的一张照片”，而不是带机器人动作的时间序列。原始图像分辨率随数据集、场景及缩放设置变化，不虚构一个统一的224×224输入。

| 字段 | 形状/内容 | 来源及用途 |
|---|---|---|
| RGB图像 | 代码中转为`3×H×W` | 外观监督；H、W由实际图像决定 |
| 相机内参 | 焦距/主点或由FoV换算的投影参数 | 将三维点投影至该观测 |
| 相机外参 | 旋转、平移 | 确定相机视角与坐标变换 |
| 初始化点云 | `N×3`位置及颜色 | 初始化高斯中心/外观；不是几何评测真值 |
| 训练/测试视角划分 | 相机集合 | 训练用来拟合，测试用来评价；不能拿测试图优化后还称独立测试 |

官方COLMAP入口读取`images.bin`/`cameras.bin`，失败时尝试文本格式，随后读取`points3D.bin`并组织点云。`readColmapSceneInfo`默认`llffhold=8`且开启`eval`时按排序后索引每8张留1张；这是该代码入口的默认划分行为，**不是论文所有数据集均遵守的统一协议**（`scene/dataset_readers.py:132–171`）。

代码定义支持Blender格式入口；本次讨论的论文定量证据主要来自T&T、DTU、Mip-NeRF360和DeepBlending。未下载完整场景数据，表中给出接口字段而非伪造的真实帧数值。④的数据检查与⑥的玩具数值例子分开。

### 3.4 输入输出信息流

```text
多视角RGB + 相机 + 初始点云
  → 初始化逐场景高斯参数
  → 0–3000：外观拟合与激进增密
  → 3000–8000：增加高斯几何正则，继续完善表示
  → 第8000轮：确定重要高斯子集并初始化支点符号值
  → 8000–18000：网格参与优化
      高斯参数 → 支点(约9K×3) + 当前四面体连接(T×4)
      可学习符号值(约9K) ───────────┘
        → Marching Tetrahedra → 网格(V×3, F×3)
        → 网格深度/法线 ──┐
      高斯深度/法线 ────┴→ 体表一致性损失
      RGB拟合 + 高斯正则 + 防侵蚀/内部正则
        → 反向传播 → 更新参数 → 下一轮
  → 最终提取并导出网格 / 保留高斯表示
```

K为选中的高斯数，T为四面体数，V/F为最终顶点/面数，均随场景和过滤变化，不是固定网络输出长度。

**周期必须分清：** 附录B.1说明网格参与优化从第8000轮开始，之后每轮提取网格；Delaunay连接每500轮更新，内部占据标签约每200轮更新。这几个计数的对象不同。三角化并非每轮都重算，也不是从第1轮就开始网格约束。

当前代码把`compute_mesh_regularization(...)`的结果加到总损失，再执行`loss.backward()`（`train.py:283–312`）。最终导出入口是`mesh_extract_sdf.py:48`；代码将训练和导出分成两个入口，不代表训练中没有提取网格。

## 4. 评价指标、公式与算法

### 4.1 指标表

| 指标 | 趋势 | 测什么 | 不能据此推出什么 |
|---|---|---|---|
| F1-score | 越高越好 | 给定距离阈值下重建准确率与完整性的调和平均 | 不是所有细节/表面内部均正确的保证 |
| Chamfer Distance | 越低越好 | 重建与参考几何的双向邻近距离，按相应基准协议汇总 | 不可与F1数值直接比大小 |
| PSNR / SSIM | 越高越好 | 渲染图像与参考图像的误差/结构相似性 | 不能直接代替背景三维真值 |
| LPIPS | 越低越好 | 感知特征距离 | 不能因某个PSNR较高就默认它也更好 |
| 顶点数/存储/时间/显存 | 视任务取舍 | 输出复杂度或计算资源 | 不同表的分辨率、基线运行口径不能混用 |

### 4.2 公式精读

③的目标是弄清损失在迫使什么改变。以下按原文式号记录；公式来源为PDF第5–7页，tex 256–437。所有数值例子在§7.4明确标为示意。

**式(1)：高斯→空间支点。**

$$p_{k,i}=\mu_k+R_k(s_k\odot b_i),\quad i=0,\ldots,8.$$

$\mu_k$是中心，$s_k$是三轴尺度，$R_k$是旋转，$b_i$为单位包围盒8个角点和中心。先缩放、再旋转、再平移，位置随高斯改变。支点跨越表面两侧，有利于找到符号变化。

**式(2)：异号边上的表面位置。**

$$v_n=\frac{f_{k,i}p_{k',j}-f_{k',j}p_{k,i}}{f_{k,i}-f_{k',j}}.$$

两端支点为$p$，符号值为$f$。异号边上通过线性插值找零点，梯度能回到位置与符号值。整数连接只决定使用哪条边；不能将其选择过程解释为平滑函数。

**式(3)(4)：保持高斯外观与自身几何的一致性。**

$$\mathcal L_{vol}=(1-\lambda_{RGB})\mathcal L_1+\lambda_{RGB}\mathcal L_{D\text{-}SSIM}+\lambda_N\mathcal L_N.$$
$$\mathcal L_N=\sum_i(1-\mathbf N(i)\cdot\widetilde{\mathbf N}(i)).$$

L1与D-SSIM约束照片拟合；$\mathbf N$是高斯渲染法线，$\widetilde{\mathbf N}$从渲染深度的有限差分得到。两条线索不一致时，几何正则提供惩罚。相同单位法线的点积为1，惩罚为0；互相垂直时点积为0，单项惩罚为1。这是点积意义的算例，不是实验结果。

**式(5)–(7)：让体表示与表面一致。**

$$\mathcal L_{mesh}=\lambda_{MD}\mathcal L_{MD}+\lambda_{MN}\mathcal L_{MN}.$$
$$\mathcal L_{MD}=\sum_i\log(1+|D(i)-D_M(i)|).$$
$$\mathcal L_{MN}=\sum_i(1-\widetilde{\mathbf N}(i)\cdot\mathbf N_M(i)).$$

$D$与$D_M$分别为同视角高斯和网格的深度，$\mathbf N_M$为网格面法线。深度约束表面在哪里，法线约束朝向；二者互补。对数项缓和大深度残差的影响。源码中进一步做可见性遮罩与平均；论文按求和写法表达，权重与尺度不能脱离实现直接复算成整幅损失（`regularization/regularizer/mesh.py:523,558`）。

**式(8)：防止细几何侵蚀。**

$$\mathcal L_{erosion}=\sum_{g\in G_{Del}}\max(0,f_{\mu_g}).$$

只对选中高斯的**中心支点**施加：鼓励它们的符号值为负，避免细杆一整块变成外部而消失。不能将其误读为把所有支点都推成负值；那会损伤过零表面。

**式(9)：清理内部伪影。**

$$\mathcal L_{interior}=\sum_p H(\sigma(-f_p),o_p)\,o_p.$$

$o_p\in\{0,1\}$来自网格可见深度，表示支点是否在表面内部；$H$为交叉熵，$\sigma$为sigmoid。对判为内部的点要求负符号值，避免内部混乱结构；外部点已有渲染监督，不额外统一约束。标签更新约每200轮，并非每步重新做完整多视角占据计算。

**式(10)(11)：总目标。**

$$\mathcal L=\mathcal L_{vol}+\mathcal L_{mesh}+\mathcal L_{reg}.$$
$$\mathcal L_{reg}=\lambda_{erosion}\mathcal L_{erosion}+\lambda_{interior}\mathcal L_{interior}.$$

| 原文训练设置 | 数值/范围 | 出处 |
|---|---|---|
| 优化器 | Adam | 附录B.1 |
| SDF学习率 | 0.025 | 附录B.1；高斯沿用RaDe-GS学习率 |
| 外观混合权重 | λRGB=0.2 | 附录B.1 |
| 几何一致性权重 | λN=λMD=λMN=0.05 | 附录B.1 |

### 4.3 算法精读

算法核心是“空间支点＋符号场＋局部插值＋几何反馈”。与只在最终体表示上取一次等值面相比，MILo能在优化过程中改变后续表面；与固定拓扑的网格细化相比，它还会周期性更新连接。

可微路径不对离散三角化求导：`functional/delaunay.py:57`对支点先`detach()`再计算四面体连接。`functional/mesh.py:93–104`按连接取得异号边端点，再对端点位置和符号值插值。**这是分段可微的几何优化，不是所有拓扑变化都拥有连续导数。**

### 7.4 例子走一遍（对照代码）

**示意例子，非论文实测、非完整训练复现。** 只取一条四面体边，令两端支点p₀=(0,0,0)、p₁=(1,0,0)，符号值f₀=-0.25、f₁=0.75。两端异号，表面穿过该边。

$$v=\frac{-0.25(1,0,0)-0.75(0,0,0)}{-0.25-0.75}=(0.25,0,0).$$

源码以等价的绝对值权重实现（`functional/mesh.py:99–104`）：

```python
norm_sdf = end_sdf.abs() / end_sdf.abs().sum(dim=1, keepdim=True)
verts = end_points[:, 0, :] * norm_sdf[:, 1, :] + end_points[:, 1, :] * norm_sdf[:, 0, :]
```

第一轮交点在边长25%的位置。若只为观察敏感性，将f₀手动改为-0.30，f₁仍为0.75，则下一次提取的位置为0.30/1.05≈0.285714，表面会沿同一条边移动。这一步**不是模拟作者Adam更新**，只说明符号值如何控制表面。

实际优化中，网格渲染得到深度/法线；若与高斯分支不一致，误差通过上面的插值回到f值和支点位置，再回到高斯参数。连接未更新时，下一轮仍可在相同四面体上移动表面；到约500轮更新点时，重新计算连接，以适应几何变化。网格顶点数量也可能随符号与连接变化，并非一个固定输出长度。

整条链：观测及当前高斯 → 支点与符号值 → 四面体边插值 → 网格 → 几何渲染与一致性损失 → 参数更新 → 再提取。数值复算结果记录在PPT项目的`validation/toy_interpolation.json`。

## 13. 我的理解与批判

### 13.1 课程汇报中的评价草稿

本次汇报可强调：MILo把网格从训练后的导出物变为优化中的几何约束，在整场景表面重建上提供了有价值的精度与复杂度折中；代价是额外计算，其优势要按具体场景与指标判断。该表述是有原文依据、已获授权起草的报告评价，仍待本人审读后形成最终口头表达。

### 13.2 最容易误读的地方

1. “可微网格提取”不等于Delaunay连接本身可微。
2. “每轮提取”指网格阶段，不是所有18000轮从头同步进行。
3. “渲染更像”不等于几何真值更准确，也不等于所有图像指标更好。
4. “轻网格”是与特定基线和设置比较，不是所有场景统一十倍。
5. 静态重建结果能参与动画，不等于输入动态视频并正确重建运动。

### 13.6 一分钟问答核对

1. **为什么提取Mesh？** 显式表面有明确顶点及连接，便于很多编辑、形变与几何处理。高斯和网格擅长的任务不同，不能说所有引擎只认网格或没有Mesh就完全不能碰撞。
2. **离散三角化如何反传？** 固定当前连接时，异号边交点对支点位置和符号值可微；Delaunay连接本身不求连续梯度，周期性重算。本论文设置为500轮更新连接。
3. **DTU为何持平？** 表3平均CD确实同为0.68。作者将DTU描述为受控物体场景，认为事后提取已有效；这是作者的解释，不是通过单一控制变量验证的因果结论，也不能说DTU没有细结构。
4. **未来热点有什么证据？** MeshSplatting官方页标CVPR2026并比较MILo，TopoSurfel是2026年8月arXiv预印本；它们说明相关问题持续被研究，不证明未来一定爆发，也不是两篇均已核验的顶会录用。
5. **能否重建跳舞人体、无缝用于CAD？** 本文实验围绕静态场景；动态扩展仍属未来方向。作者提供Blender编辑动画演示，不等于验证动态重建、工业CAD或任意引擎的端到端兼容。
