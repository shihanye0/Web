# draw.io

开源图表绘制工具（ diagrams.net 桌面版）。本机版本 **26.0.16**（winget，2026-09-12，命令别名 `DrawIO`）。

## 它解决什么

画论文/汇报里的结构图：方法框架图、实验流程图、系统架构图、威胁模型示意图。原生支持导出**矢量 PDF/SVG**，直接满足期刊和学位论文的插图要求。

## 如何使用

1. 开始菜单或 `DrawIO` 命令启动 → 选"创建新绘图"。
2. 左侧形状库按需搜索（流程图、UML、网络、机器人相关图形都有）；双击图形编辑文字，拖动对齐有吸附线。
3. 文件默认存 `.drawio` 格式（可再编辑），导出用 文件 → 导出为：论文插图选 **PDF（裁剪）** 或 SVG；PPT/Word 用 PNG（300dpi）。
4. 中文字体默认可正常显示导出，无需额外配置。

## 适用场景

- 论文第 3 页那张" overall framework "图
- 开题/组会 PPT 里的方法对比图、实验 pipeline
- [[VLA科研工具与论文阅读工作流]] 第 2 节那类工作流示意图

## 搭配

- 本机装了 `drawio-mcp`（npm 全局包），可让 AI 编程助手直接生成/修改 .drawio 图——画流程图时先让 AI 出草稿再手调
- 导出的 SVG 可直接嵌入 Obsidian 笔记（嵌入语法：感叹号 + 双方括号包文件名）
- 复杂插画交给 Photoshop，结构示意图一律 draw.io——别用 PS 画流程图
