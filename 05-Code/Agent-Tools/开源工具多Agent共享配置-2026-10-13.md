# 开源工具多 Agent 共享配置

本轮将 REA 与 text-to-cad 接入 Codex、Claude Code、Antigravity、DSH。REA 提供软件制品分析入口；text-to-cad 补充精确尺寸建模与 STEP 导出。其他候选项目按已有工具的覆盖程度保留或暂缓安装。

本笔记记录 2026-10-13 的安装和验证结果。候选项目对照采用本次调研于 2026-10-12 核对的本机基线，版本和路径随升级可能改变。项目热度属于选择线索，不作为重复安装的理由。

## 2026-10-20 增补：Qoder 接入

Linux 主机的共享真源是 `~/.agents`，结构与上文 Windows 主机一致：`skills/`、`rules/`、`agents/AGENTS.md`、`mcp/servers.yaml`，投影脚本仍是 `~/.agents/bin/sync-profile`。Qoder 桌面端（qoder-ide 1.34.0）与 `qodercli 1.1.74` 共用 `~/.qoder`。

| 资产 | Qoder 原生入口 | 本轮处理与结论 |
| --- | --- | --- |
| Skills | `~/.agents/skills`（第三方技能位，默认扫描） | 已在共享位直接生效，不再建立 `~/.qoder/skills` 链接 |
| Rules | `~/.qoder/rules/*.md`、`*.mdc`（用户级） | 新增 `agents-hub.md` 软链到 `~/.agents/agents/AGENTS.md`；无 frontmatter 默认 alwaysApply，单文件上限 50 KB |
| MCP（IDE） | `~/.qoder/mcp.json` | 投影 `codegraph`、`aihot`、`puppeteer`；该文件被 IDE 监视，写入后配置重载，无需重启宿主 |
| MCP（CLI/会话） | `~/.qoder/settings.json` 的 `mcpServers` | 同一组服务器合并写入，保留原有 `enabledPlugins`、`security` 等键 |

需要记住的三点：

- IDE 与 CLI 读的不是同一个文件。只写 `mcp.json` 时 `qodercli mcp list` 报“无配置”，会话启动透传的 `mcpServers` 也会是空；只写 `settings.json` 则 IDE 的 MCP 面板看不到。两处必须同源投影。
- Qoder 原样透传 `env`，不展开 `${VAR}`。`glm-vision` 只声明变量名且本机未设 `GLM_API_KEY`，因此没有投影给 Qoder。
- `codebase-memory-mcp`、`rea` 维持 dsh 口径暂不投影：Qoder 自带代码索引，REA 按任务再单独接。Qoder 的 commands/plugins 走自身插件体系，同样不投影。

**FACT：** `qodercli mcp list` 列出 `codegraph`、`aihot`、`puppeteer` 三个 stdio 服务，状态均为 Connected。

**FACT：** 按配置里的原生命令逐个做 stdio 握手，`initialize` 与 `tools/list` 均成功：codegraph 1.6.2（1 个工具）、aihot 2.0.0（8 个工具）、puppeteer 0.1.0（7 个工具），合计 16 个工具可枚举。

## 验证结果和边界

**FACT：** 从四份原生配置提取命令，分别完成 REA/CAD 共 8 次 MCP 初始化、工具枚举及业务调用。Claude Code 原生 CLI 显示两个服务均 Connected；Codex CLI 可读取 CAD 配置，Antigravity CLI 可列出两项服务。

**FACT：** CAD 在 Windows 上加载内核，并生成 STEP、STL、GLB。回读 STEP 为一个实体，外包尺寸 `40×20×6 mm`，体积约 `4800 mm³`；STL 有 12 个三角形，GLB 含一个网格，截图已人工查看。

**UNRESOLVED：** 首次四路并发启动 CAD Viewer 时，一路返回启动失败。通过官方命令启动 Viewer 后，四个入口重测均通过；尚未证明首次失败的根因或并发冷启动长期稳定性。排障命令见 CAD 说明。

**未覆盖：** 当前已运行的桌面聊天会话尚未逐个重载后验收；DSH 桌面宿主尚未启动实测。现有 Codex 会话不一定立即出现新工具，需新会话或客户端原生重载。REA 的 Ghidra/IDA、CAD 工程图/DFM/URDF 的真实工程任务未验收；Skill 可发现不等于所有功能已通过。

平台检查中 Codex、Claude Code、Antigravity 均可见 15 个登记公共 MCP ID；DSH 存储有 7 项，其中包括本轮 REA/CAD，未把其余 8 项强行同步。Antigravity 插件入口、DSH 规则入口仍有既有 `UNRESOLVED` 登记，不属于本轮两项工具新增失败。
