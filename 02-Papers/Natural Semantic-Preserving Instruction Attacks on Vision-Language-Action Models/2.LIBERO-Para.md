## 四、最重要的：什么叫 Super-additive Interaction（超加性交互效应）？

这个名字听起来复杂，其实理解计算方式后非常直观。

先解释 Interaction（交互效应）。

假设：

- 只改动作词，会让机器人成功率下降。
    
- 只改物体词，也会让成功率下降。
    
- 如果两者同时改写，可能会产生比各自影响简单相加还要严重的结果。
    

这就涉及交互效应。

Super-additive（超加性）是指联合影响超过各自影响之和。

因此，LIBERO-Para 的优势就在于：

不仅能够测量每个因素单独的影响，还能比较它们联合出现时的影响。

> 以前的部分 VLA 鲁棒性研究只是直接改写整句话，没有根据语言学理论细分究竟修改了什么。LIBERO-Para 则把机器人指令拆成动作和物体两个核心维度，使用已有语言学分类体系设计改写方式，最终形成 43 种细粒度类型。这种设计不仅能分别评估动作改写和物体改写的影响，还能发现两者组合时产生的额外性能下降。

记住三个对应关系：

Linguistic Categorization = 按语言学规则分类改写。

Factorization = 把动作和物体两个改写因素拆开研究。

Super-additive Interaction = 两种改写共同造成的性能下降，超过单独影响之和。

在不改变机器人原始任务的前提下，可以通过哪几种方式改变动作的语言表达，从而测试 VLA 模型的鲁棒性？
作者把动作表达的变化分为三大类：

1. Lexical Variation（词汇变化）：换词，不明显改变句子结构。通过替换动作动词，或者增加副词，改变动作的语言表达。

这些变化的共同特点是：句子的基本结构没有发生明显改变，主要是词汇本身发生变化。

作者希望通过这类实验研究：机器人是否过度依赖训练时见过的固定动作词？
    
2. Structural Variation（句法结构变化）：改变动作在句子中的组织方式。包括并列结构和从属结构
    
3. Pragmatic Variation（语用变化）：不直接发出命令，而是通过请求、提问或暗示表达同一个操作意图。
不直接告诉机器人“做什么”，而是通过自然语言中的需求、请求、问题或暗示，让机器人理解应该执行什么操作。

| 语用类型                        | 论文 Figure 3 中的例子                | 含义         |
| --------------------------- | ------------------------------- | ---------- |
| Need Statement（需求陈述）        | I need the stove turned on.     | 我需要炉灶被打开   |
| Embedded Imperative（嵌入式祈使）  | Could you turn on the stove?    | 你能打开炉灶吗？   |
| Permission Directive（许可式指令） | May I have the stove turned on? | 能帮我把炉灶打开吗？ |
| Question Directive（疑问式指令）   | Is the stove heating up?        | 炉灶开始加热了吗？  |
| Hint（暗示）                    | The stove is still off.         | 炉灶还没打开     |
作者把机器人动作指令的改写分为三个层次：换用什么词（Lexical）、怎样组织句子（Structural）、以什么交流方式表达操作意图（Pragmatic），并依据已有语言学理论将它们细分成十种类型，用来系统评估 VLA 对不同动作表达方式的鲁棒性。


3.2 Object Variation（物体指称变化）
在保持机器人原始任务不变的情况下，不修改动作，而是改变指令中对物体的称呼，观察 VLA 是否还能正确识别和操作同一个物体。
|类型|中文|改写方式|
|---|---|---|
|Addition|添加|给物体名称增加描述信息|
|Same-polarity Substitution (Contextual)|语境相关的同义替换|根据具体场景使用合适的替代称呼|
|Same-polarity Substitution (Habitual)|常规同义替换|使用日常语言中常见的近义词或同义词|
### 1. Addition（添加）

不替换原来的物体名称，而是在其基础上增加描述。
不过需要注意：添加的描述必须符合实际物体，不能凭空增加与场景不符的属性。例如，如果炉灶并非燃气式，那么添加 `gas` 就可能改变指称范围。

### 2. Same-polarity Substitution（Contextual）：语境相关的同义替换

这一类型是：结合当前场景，用另一个在该语境下能够指向同一物体的词语替换原名称。
这类改写实际上在测试 VLA 的上下文物体指称能力（Contextual Object Grounding）。

### 3. Same-polarity Substitution（Habitual）：常规同义替换

这一类型使用语言中较常见、约定俗成的替代名称。

与 Contextual 的主要区别是：

- Habitual：依赖词语在日常语言中的常规近义关系。
    
- Contextual：依赖特定场景，使两个不一定普遍同义的表达指向相同目标。
作者认为，机器人指令中的物体通常通过简单的名词短语表达，因此将物体改写分成三种：增加描述、使用语境相关的替代称呼、使用常规近义称呼。通过只改变物体的语言表达，测试 VLA 是否真正理解它所操作的目标物体，而不是依赖训练中固定的物体名称。


4 PRIDE: Paraphrase Robustness Index  in Robotic Instructional DEviation
为了更清晰、可解释地评估 VLA 模型的语言改写鲁棒性，作者提出了 PRIDE 指标，用于量化原始指令与改写指令之间的语言差异。

与传统通用语言评价指标不同，PRIDE 专门针对机器人操控指令，将语言变化拆分为两个维度：

1. Keyword Variation（关键词变化）：衡量动作词、物体名称等关键内容词的变化程度。例如 `stove → cooktop`。
    
2. Structural Variation（结构变化）：衡量句法结构的变化程度。例如 `Turn on the stove` → `Could you turn on the stove?`。
    

核心意义： 不仅判断 VLA 是否完成任务，还结合指令的改写程度，分析模型对不同语言变化的适应能力。
一句话总结：PRIDE 通过关键词差异和句法结构差异衡量语言改写程度，再结合任务执行结果，更细致地评价 VLA 的语言鲁棒性。

4.1 关键词相似度 SK
机器人指令最重要的往往不是整句话有多相似，而是决定任务的关键内容——动作和物体——发生了什么变化。
BLEU 是一种通过比较词语及连续词组（n-gram）的重合程度，衡量两段文本相似性的方法。
但是，对 BLEU 来说：

- A 保留了原句中的 `pick up the bowl`，词组重合较多。
    
- B 虽然表达相同的抓取动作，但将 `pick up` 换成了 `grab`，词组重合减少。
    

因此，BLEU 往往更容易给 A 较高的相似度。
BLEU 主要衡量文字形式上的重合，不直接理解 `pick up` 与 `grab` 之间的动作语义关系。
某些对机器人核心任务影响较小的语法词，也可能影响传统文本相似度指标的计算结果。

作者设计了一个关键词层面的相似度指标，重点比较表示动作和物体的实词，排除功能词。
![[实词和功能词.png]]

\(S_K\) 越高，意味着两条指令的关键内容词在向量语义空间中越相似；越低，表示关键内容词的差异越明显。

在 LIBERO-Para 的研究设定中，原始指令和改写指令已经被当作一组经过语义保持检查的释义对。

|问题|解决方式|
|---|---|
|两句话是否要求相同的任务？|释义生成和语义保持验证|
|在任务相同的前提下，核心关键词变化有多大？|关键词相似度 \(S_K\)|
机器人操控指令通常由少数关键的动作词和物体名称决定任务意图。传统 BLEU 等 NLP 指标主要关注词汇或词组重合，容易受到同义词替换、词序变化以及功能词的影响，不能充分反映任务关键内容词的相似程度。

因此，LIBERO-Para 在已验证语义保持的指令对上，提取表示动作和物体的实词，排除功能词，并基于词向量计算关键词相似度 \(S_K\)，用于衡量改写前后核心词汇的变化程度。

最重要的区别：BLEU 主要关注“文字有多像”，而 \(S_K\) 重点关注“决定机器人任务的关键词有多相似”。

如何计算原始指令与改写指令之间的关键词相似度。
提取关键词 → 找到最相似的词 → 计算平均相似度。
\[ S_K(O,P)=\frac{1}{n}\sum_{i=1}^{n} \max_{j\in\{1,\ldots,m\}} \cos\left(e(o_i),e(p_j)\right) \]
各个符号的含义如下：

| 符号                    | 含义                      |
| --------------------- | ----------------------- |
| \(O\)                 | 原始指令提取出的实词集合            |
| \(P\)                 | 改写指令提取出的实词集合            |
| \(o_i\)               | 原始指令中的第 \(i\) 个实词       |
| \(p_j\)               | 改写指令中的第 \(j\) 个实词       |
| \(n\)                 | 原始指令的实词数量               |
| \(m\)                 | 改写指令的实词数量               |
| \(e(\cdot)\)          | 使用 Sentence-BERT 得到的词向量 |
| \(\cos(\cdot,\cdot)\) | 两个词向量之间的余弦相似度           |
| \(\max\)              | 选出相似度最高的那个词             |
| \(\sum\)              | 将每个原始关键词的最高相似度加起来       |
Embedding（嵌入向量）可以理解为：把词语转换成一组数字，让计算机能够比较它们在向量空间中的相似程度。
![[余弦相似度.png]]

对每个原始词寻找最高相似度

原始指令中那些决定任务的关键内容，在改写指令中保留得怎么样？

而不是严格要求两句话中的所有词语都一一对应。


作者首先从原始指令和改写指令中提取表示动作和物体的实词，并使用 Sentence-BERT 将其转换为词向量。随后，对原始指令中的每个实词，计算它与改写指令所有实词的余弦相似度，选取最大值，最后对所有原始实词的最大相似度求平均，得到关键词相似度 \(S_K\)。

核心公式：

\[ \boxed{S_K(O,P)=\frac{1}{n}\sum_{i=1}^{n}\max_j\cos(e(o_i),e(p_j))} \]

一句话理解：对于原始指令中的每个关键词，都去改写指令里找一个最相似的词，然后把这些最高相似度取平均。

还有一点对你后续研究很重要：\(S_K\) 衡量的是关键词在向量空间中的保留程度，而不是直接衡量攻击成功率，也不能单独证明两条指令的任务语义完全一致。


4.2 Structural Similarity（结构相似度，\(S_T\)）。

作者提出的方法是：把句子转换成语法树，计算两棵树之间的差异，再得到结构相似度 \(S_T\)。

整段涉及四个核心概念：

1. Syntax（句法结构）
    
2. Dependency Tree（依存句法树）
    
3. Tree Edit Distance（树编辑距离，TED）
    
4. Normalization（归一化）


依存句法树就是把句子中词语之间的语法关系，用树形结构表示出来。
![[依存句法树.png]]


什么是 Tree Edit Distance（TED，树编辑距离）？
意思是：

将一棵树修改成另一棵树，至少需要进行多少次编辑操作。

为什么论文不直接使用单词作为节点标签？
作者希望 \(S_T\) 只关注结构变化，尽量不受单词替换影响。
论文不使用词语表面形式作为节点标签，而是使用词性标签（POS）。

|原词|改写词|POS|
|---|---|---|
|Open|Open|VERB|
|the|the|DET|
|drawer|cabinet|NOUN|

这样，即使 `drawer` 变成 `cabinet`，由于两者都是名词，对句法结构的影响就很小。
核心目的：将词汇变化和句法变化尽可能区分开。
![[st公式.png]]

### ST 越大越好，还是越小越好？

- \(S_T\) 接近 1：两条指令的语法结构高度相似。
    
- \(S_T\) 较低：句法结构的差异较明显。
|维度|\(S_K\)：关键词相似度|\(S_T\)：结构相似度|
|---|---|---|
|衡量对象|实词与实词之间的相似性|两棵依存句法树的相似性|
|核心技术|Sentence-BERT + Cosine Similarity|Dependency Parsing + TED|
|对什么敏感|动作词、物体名词的替换|句法组织方式的变化|
|高分代表|关键词较相似|句法结构较相似|
|主要目的|衡量词汇改写程度|衡量句法改写程度|


关键词相似度 \(S_K\) 只能衡量核心词汇的保留程度，无法充分反映句法结构的变化。因此，作者提出结构相似度 \(S_T\)，通过计算原始指令与改写指令的依存句法树编辑距离（TED），量化两者的句法差异。

为减少词汇替换对结构相似度的干扰，作者使用词性标签（POS）表示节点，使用依存语法关系表示边，而不是直接比较单词。同时，将 TED 除以两棵树的节点总数进行归一化。

\[ \boxed{S_T=1-\frac{TED(T_O,T_P)}{|T_O|+|T_P|}} \]

一句话总结：\(S_T\) 通过比较两条指令的语法树需要多少次编辑才能互相转换，衡量句法结构的变化程度；相似度越低，说明改写后的句法结构与原始指令差异越大。

还有一个需要理解的点：\(S_T\) 衡量的是句法结构差异，不是任务语义差异。 两条指令即使语义完全一致，句法结构也可能很不一样，这恰好是 LIBERO-Para 希望测试的情况。


依存句法树的节点确实对应原句中的单词，但 LIBERO-Para 在计算结构相似度 \(S_T\) 时，并不直接使用单词本身作为节点的比较标签。

这里需要区分两个概念：

1. 节点（Node）代表什么？ 代表句子中的一个词。
    
2. 节点标签（Node Label）是什么？ 论文使用这个词的词性（POS），而不是词汇本身。

4.3 PRIDE Score
如何将两种相似度结合起来，再考虑机器人是否成功完成任务，最终得到一个能够衡量 VLA 语言改写鲁棒性的指标？
作者分两步完成：

1. 计算 PD（Paraphrase Distance，释义距离）：衡量指令改写程度。
    
2. 计算 PRIDE：结合改写程度和任务执行结果，衡量模型的改写鲁棒性。

PD 想衡量的是两条指令的差异程度。

因此：

- 相似度高 → PD 小 → 改写程度较小。
    
- 相似度低 → PD 大 → 改写程度较大。
-

机器人成功执行的改写指令越复杂，获得的鲁棒性得分越高；如果任务失败，则不获得鲁棒性得分

| 指令      | PD  | 执行结果 | PRIDE |
| ------- | --- | ---- | ----- |
| A（简单改写） | 0.1 | 成功   | 0.1   |
| B（中等改写） | 0.4 | 成功   | 0.4   |
| C（复杂改写） | 0.8 | 失败   | 0     |
| D（复杂改写） | 0.7 | 成功   | 0.7   |
PRIDE 是一种以任务成功为条件的鲁棒性得分。

第一，PD 高不代表任务语义已经改变。

LIBERO-Para 要求改写前后任务意图保持一致。

所以这里的“语义和结构偏离程度更大”，主要指词汇表达和句法结构发生更明显的变化，而不是机器人应该完成另一项任务。

第二，PRIDE 高不代表攻击效果更强，恰恰相反。

这是与你的 VLA 攻击课题直接相关的一点。

PRIDE 评价的是模型的鲁棒性，而不是攻击者的能力。

同样一条 PD = 0.8 的指令：

- 机器人成功 → PRIDE = 0.8，说明模型具有处理该改写的能力。
    
- 机器人失败 → PRIDE = 0，说明模型没有成功处理该改写


4.3 PRIDE Score

作者将关键词相似度 \(S_K\) 和结构相似度 \(S_T\) 按照权重 α 结合，定义释义距离 PD，用于衡量原始指令与改写指令之间的语言差异。α 默认设置为 0.5，使词汇和结构因素具有相同权重。

在此基础上，作者提出 PRIDE 鲁棒性指标：任务成功时获得对应的 PD 分数，失败时得分为 0。相比传统二元成功率，PRIDE 能进一步区分模型是只能处理简单的语言改写，还是能够成功处理改写程度较大的指令。

三个指标的关系：

\[ \underbrace{S_K+S_T}_{\text{两类相似度}} \quad\longrightarrow\quad \underbrace{PD}_{\text{语言改写程度}} \quad\longrightarrow\quad \underbrace{PRIDE}_{\text{结合任务成功的鲁棒性得分}} \]

一句话总结：PD 衡量指令改写了多少，PRIDE 衡量 VLA 能否成功处理这些改写；两者结合，使语言鲁棒性的评估更加细致。


第 5 章 Experiment（实验）
核心结论：不同架构的 VLA 模型都存在明显的语言改写鲁棒性问题；物体名称变化比动作表达变化的影响更大；同时修改两者会产生超加性交互效应，而 PRIDE 能比普通成功率更细致地揭示这些问题。
此外，作者设计了两组控制实验：

- OFTgoal vs. OFTmixed： 比较微调数据范围不同，是否会影响语言鲁棒性。
    
- π0.5 Full vs. Expert-only： 比较同时微调 VLM 和 Action Expert，与冻结 VLM、仅微调 Action Expert 的区别。
    

目的在于判断：语言改写造成的性能下降，是否与模型架构、训练数据范围或微调策略有关。


5. Experiment（实验设置与结果）

作者选取了覆盖四类架构的七种 VLA 配置，在 LIBERO-Goal 和 LIBERO-Para 上进行对比，并通过不同微调数据范围与训练策略分析语言改写鲁棒性。

实验得到四项主要发现：

1. 跨架构脆弱性： 所有模型在语言改写后成功率均下降 22.8–51.9 个百分点，说明语言改写鲁棒性不足是跨架构的普遍现象。
    
2. PRIDE 的有效性： 相比传统 SR，PRIDE 能区分模型是主要成功于简单改写，还是也能成功处理困难改写，并与成功率表现出较强相关性。
    
3. 物体变化是主要影响因素： 相比动作表达变化，物体指称的词汇替换通常造成更严重的性能下降。
    
4. 超加性交互效应： 同时修改动作与物体的成功率下降 42.6 个百分点，超过单独修改两者的下降幅度之和 29.3 个百分点。
    

一句话概括：这组实验不仅验证了 VLA 模型普遍存在语言改写鲁棒性问题，还进一步发现物体指称变化是主要薄弱点，而动作与物体的组合改写会显著放大这种问题。

对你的 VLA 攻击研究而言，尤其值得关注后两项发现，它们为研究语义保持条件下的物体指称攻击，以及不同语言因素的组合攻击提供了实验依据。


6.实验分析
发现一：语言改写脆弱性在不同模型架构、训练数据规模和微调策略下普遍存在。
作者主要想回答一个问题：

VLA 在语言改写后成功率大幅下降，究竟是特定模型架构的问题，还是训练数据、微调方式造成的？
结论：VLA 的语言改写脆弱性并非某一种架构特有的问题，增加模型参数量也不必然带来更好的语言鲁棒性。
结论：增加任务级训练数据的多样性，并不必然提高模型对语言表达变化的鲁棒性。

## VLM Training Strategy：不同微调策略的影响

作者比较了两种 π0.5 模型。

- π0.5 Full： 同时微调 VLM 和 Action Expert。
    
- π0.5 Expert-only： 冻结 VLM，仅微调 Action Expert。
    

|指标|π0.5 Full|π0.5 Expert-only|
|---|---|---|
|VLM|参与微调|冻结|
|Action Expert|参与微调|参与微调|
|LIBERO-Goal SR|97.6%|78.6%|
|LIBERO-Para SR|71.4%|39.1%|
|PRIDE|65.4%|32.0%|
|改写后成功率下降|26.2 pp|39.5 pp|

结果表明：

第一，联合微调效果明显更好。 π0.5 Full 在原始任务和改写任务上的成功率都显著高于 Expert-only。

第二，冻结 VLM 并不能自动保留更好的语言鲁棒性。 Expert-only 在改写任务上的成功率仅为 39.1%。

第三，即使联合微调，语言改写脆弱性依然存在。 π0.5 Full 的成功率仍然从 97.6% 下降到 71.4%。

6.1 Finding 1：语言改写脆弱性具有跨架构、跨训练设置的普遍性。

作者从模型架构、训练数据范围和微调策略三个方面研究 VLA 语言改写鲁棒性，得到以下发现：

1. 架构差异： 七种 VLA 配置在语言改写后均出现 22.8–51.9 pp 的成功率下降，说明语言改写脆弱性普遍存在，不能简单通过更换架构或增大参数规模解决。
    
2. 训练数据范围： OFTmixed 的任务多样性扩大约四倍，但与 OFTgoal 的成功率下降幅度相近（32.4 pp vs. 33.2 pp），表明增加任务多样性不一定能改善语言鲁棒性。
    
3. 微调策略： π0.5 联合微调 VLM 和 Action Expert 的表现明显优于仅微调 Action Expert，但两种策略都存在明显的语言改写性能下降。
    

最终结论：

VLA 的语言改写鲁棒性问题，无法仅由模型架构、训练数据范围或微调策略解释，可能涉及更深层次的语言理解与任务映射问题。


Object-level variation（物体指称变化）是主要失败来源，Action indirectness（动作间接表达）是次要但额外的失败因素。
作者认为：

> 当前 VLA 更依赖**表层关键词匹配**，而不是对物体进行真正的语义理解。


增加任务种类 ≠ 提高物体语言改写鲁棒性。
训练数据增加的是 **task diversity（任务多样性）**，但是没有必然增加 **linguistic diversity（语言表达多样性）**。

### Semantic Grounding

可以简单理解成：

> **把语言中的词/概念，正确对应到现实世界中的具体对象、动作和状态。**


根据失败轨迹 与成功执行轨迹的相似度对失败进行分类。

6.3 Finding 3：Failures Are Predominantly Planning-Level, Not Execution-Level。

中文：发现三：VLA 在语言改写后的失败，主要发生在任务识别与规划层面，而不是底层动作执行层面。
![[失败轨迹和成功轨迹的对比.png]]

作者将失败划分为两种类型：

|类型|含义|作者的解释|
|---|---|---|
|Near-GT|失败轨迹接近成功轨迹|执行层面失败（Execution-level）|
|Far-GT|失败轨迹明显偏离成功轨迹|规划层面失败（Planning-level）|

简单理解：

Near-GT：大体往正确方向做了，但没有完成。

Far-GT：从运动轨迹来看，机器人执行的就不像原本要求的任务。

什么是 Pseudo Ground-Truth（伪真实轨迹）
作者需要一个参考标准，判断失败轨迹是否偏离了正确路径。
收集同一任务下所有成功的机器人运动轨迹，对齐采样点后计算平均轨迹，并将其作为参考。

什么是 DTW（Dynamic Time Warping，动态时间规整）？
DTW 是一种比较两条序列相似程度的方法，允许序列在时间上进行非线性对齐。
![[DTW轨迹对比.png]]

论文使用 DTW 计算：

\[ d_i=DTW(T_i,T_{GT}) \]

其中：

- \(T_i\)：某次机器人执行的运动轨迹。
    
- \(T_{GT}\)：平均成功轨迹。
    
- \(d_i\)：两条轨迹之间的距离。
    

DTW 越小，说明失败轨迹越接近成功路径；越大，说明偏离越明显。


阈值 τ 是怎么确定的？
将同一任务中所有成功轨迹到平均成功轨迹的 DTW 距离取最大值，作为阈值。

作者认为，模型失败的主要原因可能不是机械控制精度，而是改写指令影响了任务识别和动作规划。

论文直接证明的是大部分失败轨迹显著偏离成功轨迹；“主要由任务识别错误造成”则是作者根据轨迹特征提出的机制解释。


6.3 Finding 3：失败主要发生在规划层面，而不是执行层面。

作者通过轨迹相似性分析 VLA 在语言改写后的失败原因。首先，将成功执行轨迹的平均值作为伪真实轨迹（Pseudo-GT），再利用动态时间规整（DTW）计算失败轨迹与成功参考轨迹之间的距离。

根据成功轨迹的最大 DTW 距离设置阈值 \(\tau\)，将失败划分为：

- Near-GT： 失败轨迹接近成功轨迹，作者将其解释为执行层面失败。
    
- Far-GT： 失败轨迹明显偏离成功轨迹，作者将其解释为规划层面失败。
    

实验表明，七种 VLA 配置中 79.5%–95.5% 的失败属于 Far-GT，表明语言改写后的错误主要表现为运动轨迹明显偏离，而非沿正确轨迹执行时出现的小幅误差。

结合 6.2 节的结果，作者认为物体语义扎根不足可能导致错误的任务识别，进而产生偏离正确目标的动作轨迹。

最终结论：提高 VLA 的语言改写鲁棒性，应优先关注自然语言指令到任务目标的正确映射（Instruction Semantic-to-Task Mapping），而不仅是提升底层运动控制精度。

对于你的 VLA 攻击研究，这一节尤其有价值：它提供了一种思路——除了报告攻击成功率，还可以分析攻击后的运动轨迹，判断攻击究竟让机器人偏离了目标，还是只干扰了具体执行过程。
