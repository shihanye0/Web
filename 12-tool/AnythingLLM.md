# AnythingLLM

开源本地 RAG 知识库（Mintplex Labs）。本机版本 **1.16.1**，安装位置：

```text
E:\anything_llm\AnythingLLM\AnythingLLM.exe
```

（2026-09-13 配置完成并通过端到端验收：上传文档 → 嵌入 → 提问命中且给出引用来源。）

## 它解决什么

把一批文档（PDF/Markdown/Word…）变成"可以问答的知识库"：回答基于你放入的文档内容，并标注引用来源，全程本地推理、不联网、不花钱。简单说：**给文献库配一个随叫随到、说话有出处的助手**。

| 大模型后端 | Ollama `http://127.0.0.1:11434`，模型 qwen3:4b（见 [[Ollama 本地模型]]） |

## 如何使用

1. **前提**：Ollama 在运行（托盘有图标；没开就启动 Ollama）。
2. 桌面打开 AnythingLLM → 左侧进入"科研知识库"工作区 → 把 PDF/MD 拖进对话区 → 等嵌入完成（绿色勾）→ 直接提问。
3. 提问两种模式：
   - `query`：只依据文档回答，无关问题会拒绝——**核证据用它**
   - `chat`：结合文档自由对话——**头脑风暴用它**
4. 回答下方显示引用片段，点开核对原文（和 PaperQA2 一样，这条不能省）。
5. 程序化调用（Developer API 已启用）：`POST http://127.0.0.1:3001/api/v1/workspace/<slug>/chat`，带 `Authorization: Bearer <密钥>`；密钥在应用"设置 → 开发者 API"里查看。**不要把密钥写进笔记或脚本。**

## 适用场景

- 对已读过的论文随时追问："这批方法里哪些改了 language instruction？"
- 课题组内部文档、未公开想法的隐私问答（不出本机）
- 写论文时快速翻检"我之前读过的东西"，比翻笔记快

## 与 PaperQA2 的分工（重点）

| | [[AnythingLLM]] | PaperQA2（见 [[VLA科研工具与论文阅读工作流]]） |
| --- | --- | --- |
| 费用 | 零（本地 qwen3:4b） | 调用云端 LLM，按量付费 |
| 深度 | 速查、草稿、日常追问 | 高证据密度综合、矛盾检测、严肃结论 |
| 隐私 | 完全离线 | 文档内容上传至 LLM 服务商 |
| 选用 | 高频、低风险问题 | 关键结论、要写进论文的观点 |

## 搭配

- 文献先经 [[Umi-OCR]]（扫描件）或 MinerU（复杂排版）变成干净文本，入库效果最好
- 模型不够聪明时别换更大的（显存不允许），换更干净的文档和更具体的问题
