# QuickLook

开源的"空格键预览"工具（macOS Quick Look 的 Windows 复刻）。本机版本 **4.5.0**（winget，2026-09-12）。

## 它解决什么

在资源管理器里选中文件按一下 `空格` 立即弹出预览，再按 `空格` 或 `Esc` 关闭——不用为看一个 PDF/图片/压缩包内容专门打开重型软件。

## 如何使用

1. 选中文件，按 `空格` 预览，`Esc` 关闭。
2. 开箱支持：图片、PDF、Office 文档、视频音频、代码文本；**Markdown 与压缩包预览需在 QuickLook 的"插件"页补装官方插件**（MarkdownViewer / CompressionViewer）。
3. 设置里打开"开机自启"；可自定义快捷键。

## 适用场景

- 翻下载文件夹：连续按方向键 + 空格，快速浏览几十个文件
- 文献附件（补充材料 PDF）先预览再决定是否进 Zotero
- 确认压缩包里有什么再决定解压到哪

## 搭配

- [[PowerToys]] 的 Peek 功能类似但侧重大图，QuickLook 侧重全类型轻量预览，两者共存不冲突。
- 与 [[Flow Launcher]] 组成"搜索 → 预览 → 打开"三步流。
