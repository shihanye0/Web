## 1. 研究问题与边界

### 1.1 论文要回答什么

**FACT（§I、Figure 1）**：研究对象是接收观测和语言指令、输出机器人动作的 VLA。同一任务的表述变化可能导致不同执行结果。图中原始模型能执行 “push coke can”，也能执行部分改写，但遇到另一些表述会推空、错过罐子。

论文的两层目标：系统发现多种与任务相关且会暴露模型弱点的指令；将这些指令配给已有专家示范，通过微调改善对未见表述的鲁棒性（§I L45–54、§IV-C L200–206）。没有额外采集专家轨迹是该增强步骤的设计，真机基础示范仍是另行采集的，不能混为“全程无需采数据”。

### 1.2 现有方法哪里不足

**FACT（作者对相关工作的比较，§II-A/B/C）**：训练示范的语言标注往往较窄；作者指出 ERT 可发现失败，但不显式覆盖设计者指定的攻击风格，且本文所比较的 ERT 没有后续微调闭环。纯文本的 Rainbow Teaming 缺少物理任务所需的视觉上下文。此处是论文的比较范围，不推广为所有现有方法的共同缺陷。

**作者的关键想法（§I、§IV）**：结合 Quality Diversity（既保留有用的候选，也覆盖不同表达风格）、视觉上下文和机器人 rollout 反馈，持续生成与筛选指令，再以标签增强方式微调基础策略。

**例子（Figure 1 原文）**：桌上有可乐罐；“push coke can” 与 “gently nudge the soda can” 在图中分别对应成功与失败。示例用于说明策略对语言表述敏感；不把图中单次示意当作整组成功率。表 IV 的真机原指令为 9/10、P1 为 0/10，但本轮没有把 P1 与图中文字绑定，避免错配。

与 [[01 LIBERO-Para]] 的有限对照：前一篇的已有笔记以改写评测为主线，本篇增加自适应搜索和增强微调闭环。这里不推定前一篇已被用户掌握。

### 1.3 论文不回答什么

- **FACT（§III L114–118）**：作者把目标定义为生成仍然描述同一任务 T 的新指令。这是问题定义。
- **FACT（§IV-A L163–170）**：搜索质量为成功指示量的方差 p(1-p)，最高点在 p=0.5；它偏好能力边界。不能将 Q-DIG 简化为专门最大化失败率的搜索。
- **INFERENCE**：自然、像人说话和任务相关均不足以单独证明严格语义保持；副词、动作步骤或感官描述仍须检查是否引入额外执行要求或虚假场景信息。
- **FACT（§V-A L289–294、§VI-A L464–469）**：用户研究评价 human-likeness，没有逐条证明所有指令严格语义等价的功能。Likert 自然度评分相对 Rephrase 的差异不显著，不能概括为所有自然度指标都显著胜出。
- **UNRESOLVED**：尚未逐项审查生成候选的任务等价、场景事实和可执行性；失败方差与 embedding 相似度是启发式信号，不能作为上述条件的形式保证。
- **FACT（§III、§IV）**：本文主要评测任务成功/失败；这些结果不自动给出攻击者指定错误轨迹、错误对象或危险动作的定向成功证据。

### 3.2 方法或系统结构

**本轮②架构（2026-10-27，Figure 2、§IV-A/B）**：Q-DIG 是围绕已有 VLA 的指令搜索系统。搜索阶段固定所调用的模型参数，变化的是候选指令和 archive；VLA 的监督微调发生在搜索后的阶段。

**接口（FACT）**：输入包括原任务指令、起始场景图、被选中的已有指令及其风格、目标风格；输出为按 8 类风格组织的指令 archive。图2用“Pick Coke can（拿起可乐罐）”作示例。不同图中的拿起/推开是不同示例任务，不可把跨任务动作示范混用。

1. **选择已有指令**：刚开始用原任务指令；archive 有内容后，从非空格子取一条指令作下一轮改写的参照（L179–181）。
2. **VLM Mutator 改写**：把参照指令、原有/目标风格和起始场景图交给 VLM；图中从 casual style 改为 use of adverbs，例如在口语指令上加入 carefully。视觉输入提供物体和场景上下文（L183–185）。此为设计目的，不单独保证每条候选场景事实正确。
3. **候选集筛选**：每轮生成 5 组，每组 10 条，共 50 条候选；Sentence-BERT 把每句变成向量，选组内平均两两相似度最低的一组，即 10 条，进入执行评估（L186–188、L270–275）。这一步选择整组，不是从 50 条中逐条挑最难的 10 条；语言多样性筛选也不代替任务等价验证。
4. **执行评估与风格判定**：固定的基础 VLA 接收每条候选指令和执行过程中更新的观测，在仿真中多次 rollout；成功判定得到方差分数。另一条支路由 LLM Judge 将候选实际归入 8 类之一。两条支路分别回答“执行表现如何”和“属于哪种表达风格”（L190–192）。Judge 本节承担风格分类，不是经过证明的语义等价判定器。
5. **更新 archive**：底部 z0–z7 是 8 个风格槽位。新候选所属格子为空就放入；已有指令则仅在新候选失败方差更高时替换。下一轮可使用更新后的内容继续生成（L194–195）。同风格内比较分数、跨风格保留代表，避免所有保留指令都集中在一种表达上。

| 模块 | 来源/使用什么 | 搜索阶段更新模型参数？ | 职责 |
|---|---|---|---|
| VLM Mutator | GPT-4o，论文指定 gpt-4o-2024-08-06 | 否 | 根据场景和目标风格生成改写 |
| 候选集筛选 | Sentence-BERT 句子向量 | 否 | 选择表达更分散的候选组 |
| 执行评估 | 基础 VLA＋仿真环境 | 否 | 执行动作并获得任务成功/失败反馈 |
| LLM Judge | GPT-4o 的独立判定调用 | 否 | 给实际生成的句子分类 |
| Instruction Archive | 8 类槽位，无可训练网络参数 | 更新的是槽位内容 | 每种风格保存当前最高方差候选 |

**范围与参数边界**：原文该方法节未列 GPT-4o 与 Sentence-BERT 的参数量；基础 VLA 依实验为 OpenVLA-OFT、π0.5 或 GR00T N1.6。搜索系统的循环不等于在每轮训练这些网络。具体方差公式、VLA 微调损失与动作接口分别留至③⑤。

**流程小结**：取旧指令 → 看图按风格改写 → 挑多样的一组 → VLA 执行＋Judge 分类 → 按风格与分数更新 archive → 再取旧指令。搜索结束后，才接之前解释的示范重标注与监督微调。

### 3.4 输入输出信息流

**⑤信息流（2026-10-29）**：形状按已核对OpenVLA-OFT/LIBERO配置说明，不推广为所有VLA。完整Q-DIG增强/SFT实现仍缺失。

**A．搜索链（§IV-A/B）**

    原任务指令＋起始场景图O0＋已有指令/风格＋目标风格
      → VLM生成5组×10条文本
      → Sentence-BERT选组内相似度最低的一组10条
      → 每个候选c固定，反复重置并执行完整任务（当前配置10次）
          → 当前两路RGB＋8维状态＋同一句c
          → 固定基础VLA输出8×7动作块
          → 动作队列逐步发给环境，观测随执行更新
          → 队列为空才用最新观测重新预测
          → 完整任务结束得到一次0/1结果
      → 汇总每个c的多次结果得p、J=p(1-p)（显示4J）
      → 另一支：c送LLM Judge取得实际风格
      → 按风格定位8格archive，按分数空格插入/更高替换
      → archive代表文本可供后续搜索轮改写

改写器使用任务起始场景O0；VLA执行时使用动态当前观测。搜索有三层循环：生成/归档搜索轮、固定候选多次任务评估、一次任务内多次动作块预测。搜索不更新基础VLA，也不利用后续SFT损失指导改写。

**B．监督微调链（§IV-C）**

    旧示范t时刻图像/状态＋原始或训练用生成指令
      → 图像处理、文字tokenizer、状态处理
      → VLA预测当前及未来8步（本配置8×7）
      → 与该示范t至t+7的归一化专家动作8×7比较
      → 原模型训练损失（已核对OpenVLA-OFT L1分支）
      → 反向传播、优化器更新训练方案允许更新的VLA参数
      → 继续读取其他保存样本

专家动作是监督目标，不是部署时模型输入；离线算loss不要求每次驱动环境。搜索方差不是此L1损失；GPT改写器/Judge不按动作损失训练。按记录索引配标签，不将no-op过滤后的索引强行换算成均匀实际时间。

**C．训练后执行链**

    当前主/腕部图像＋8维状态＋任务指令
      → 已微调VLA输出8×7动作块
      → 控制器/环境逐步执行
      → 取得新观测
      → 同一指令下重新调用VLA
      → 直到任务结束

执行时模型参数固定，专家轨迹不参与输入。生成器、候选筛选、Judge、archive属于准备阶段，不需要在每次动作预测时在线运行。

| 阶段 | 固定项 | 更新/保留项 |
|---|---|---|
| 搜索 | 基础VLA参数；候选评估期间文本 | 当前场景、候选、分数/风格、archive |
| 微调 | 保存的专家动作标签 | 训练方案允许更新的参数，读取不同样本 |
| 执行 | 模型参数、本次任务指令 | 当前观测、状态、待执行动作队列 |

**固定与循环边界**：固定内容不等于只编码一次，KV cache未核验。未选4组不进入该轮rollout；同格落选候选不成为当前代表，不等于日志删除。动作逐个从队列弹出，清空后重算；回放视频被记录也不自动成为正确专家标签。

**时序边界**：当前OpenVLA-OFT配置两路图像、use_proprio=True、8步动作块/每步7维。上游LIBERO默认20Hz；若沿用默认，8控制步为0.4秒仿真时间。这是配置推算，不是实测模型推理耗时、墙钟吞吐或真机频率。证据：libero_manager.py中的for prompt、range(self.n_evals)、action_queue.extend、popleft、env.step，及LIBERO env_wrapper.py。

## 4. 评价指标、公式与算法

### 4.1 指标表

| 量 | 计算或定义 | 用途 | 解释边界 |
|---|---|---|---|
| 单次任务成败 | $g_T(\zeta)\in\{0,1\}$ | 环境规则评价完整执行 | 不单独刻画语言难度 |
| 成功率 $p_c$ | 成功次数/该指令评估次数 | 汇总同一句的执行结果 | 依模型、任务及初始状态分布而定 |
| 搜索质量 $J(c)$ | $p_c(1-p_c)$ | 同风格槽位内择优，最大值0.25 | 不是微调loss；不是语义等价保证 |
| 图/代码归一化质量 | $4p_c(1-p_c)$ | 便于在0至1显示 | 正常非零重复次数下只改变尺度，不改变排序 |

### 4.2 公式精读

**③训练与搜索目标（2026-10-27）**：Q-DIG先固定策略搜索指令，再用增强后的专家示范进行监督微调。GPT-4o改写器/Judge、Sentence-BERT没有在这套搜索中训练；搜索期间VLA固定。微调期间更新哪些VLA子模块沿用各模型训练方案，本文未在方法节给出统一冻结表，不据此断言所有模型都全参更新。

#### 原文式（1）：搜索质量

$$
J(c)=\mathbb{E}_{\zeta\sim\pi(\cdot\mid\cdot,c)}[g_T(\zeta)]\left(1-\mathbb{E}_{\zeta\sim\pi(\cdot\mid\cdot,c)}[g_T(\zeta)]\right)=p_c(1-p_c).
$$

| 符号 | 含义 |
|---|---|
| $c$ | 当前固定的候选指令 |
| $\pi$ | 搜索时固定的基础VLA策略 |
| $\zeta$ | 一次完整rollout轨迹 |
| $g_T(\zeta)$ | 环境任务判定，完成目标为1 |
| $p_c$ | 对该任务初始状态分布执行时的成功概率，以重复评估估计 |

**数值示意**：10次中成功5次，$J=0.5(1-0.5)=0.25$，归一化为1；成功8次，$J=0.8\times0.2=0.16$，归一化为0.64；全成功和全失败均为0。作者用此量偏好能力边界候选，而非最大化原始失败率。代码位置：`code/src/prompt/objective_calculate.py:23`的`failure_variance`返回4倍经验Bernoulli方差；这是静态阅读，未运行模型实验。

#### 原文式（2）：各风格分别保留最好候选

$$
\left\{\operatorname*{arg\,max}_{c}J(c)\ \text{s.t.}\ m(c)=z,\ \forall z\in\mathcal{Z}\right\}.
$$

$m(c)$为Judge给出的实际风格，$\mathcal Z$含8种风格。此式表示每格分别比较$J$，而非把所有风格混成一个只留全局第一的列表。具体归档规则允许空格插入，非空格严格更高才替换。

#### VLA微调目标：沿用原模型的监督学习损失

**FACT（§IV-C L200–206，§V-B L323–327）**：将原始任务的正确专家轨迹与部分生成指令配对，沿用各VLA架构的SFT流程。Q-DIG未提出统一的VLA新loss；不能将式（1）当成对VLA参数反向传播的损失，也不能把所有模型说成统一回归损失。

教学示意只看一个动作数值：给定旧示范画面和新指令，专家动作目标为1.0，模型预测0.4。如果示例采用绝对误差，则$|0.4-1.0|=0.6$；调整模型参数以减少此类误差，希望预测靠近1.0。数值没有物理单位、不是论文真实样本；这个简化损失仅解释监督学习，不冒充所有基座的实际训练损失。真实训练可预测多维动作或动作块。

**两种目标的区别**：搜索时5/10成功的指令可获高方差；微调后同一句达到9/10成功属于执行改善，虽然$J$变小。微调目标是更好完成任务，不是保持50%成功。上述前后数值是教学假设，不是本机测量或论文特定表格。

**阶段记录**：

| 阶段 | 数据/反馈 | 改变什么 |
|---|---|---|
| 基础策略准备 | 原始专家示范；按模型训练协议 | 获得可执行原任务的基础VLA |
| Q-DIG搜索 | 候选指令、场景观测、重复rollout成败、风格分类 | 改指令与archive，不改模型参数 |
| 增强微调 | 旧专家轨迹＋原始/生成指令 | 更新VLA训练方案允许更新的参数 |
| 留出评估 | 训练未见指令下的完整任务执行 | 统计结果，不作为本轮参数更新 |

**实验数量（原文口径）**：每任务50条专家示范，8条生成指令用于增强并保留原始指令；§V-B记生成10条、随机选8条训练和2条留出。OpenVLA-OFT、π0.5微调10,000次迭代，GR00T N1.6为20,000次；LIBERO评估每条指令50次。此处50次评估与代码搜索阶段默认10次不同。正文未给统一batch size、冻结表和算力配置；不补造。

**计数未决**：§IV-C先定义$G$为生成指令数并写$G+1$组，下一句又将$G=9$解释成8条生成加1条原始，记号不自洽。§IV-A的8格最终archive与§V-B“生成10条”的取样衔接也未在这些段落中说明。可分别记录明确给出的8+1、10分8/2，不推定50条轨迹均分或最终8格直接等于10条。留④数据核查。

**训练与推理**：SFT读取已保存观测、指令与专家动作，通过原模型损失更新参数；执行时接收实时观测与固定任务指令，自主输出动作，不读取专家动作当输入。

## 7. 结果解释与失败机制

### 7.1 论文声称的发现

1. 找到更分散、覆盖更多预设风格的指令；用户研究部分指标支持更像人说话。
2. 搜索指令配给专家示范微调后，一些未见表述上的成功率提高；并非所有对照均最佳。
3. 所选真机案例有改善；不能从两条各10次的结果外推全部任务与长期可靠性。

### 7.2 结果真正证明了什么

- 表II的行是测试指令来源，列是训练增强数据来源。不能把Q-DIG行当Q-DIG训练列。
- OpenVLA在Q-DIG未见改写上+25.0个百分点，同时原句−3.6个百分点，综合82.1低于ERT87.3；对应此前讨论的已见表述保持与未见表述鲁棒性须分别评估。
- 图3的高方差不是高失败率，BERT距离不是严格语义真值，风格覆盖只相对预设8类；不能跨层推出自然合法与同任务保证。
- 可加强证据的后续工作：更广任务/人类指令分布、独立语义与场景有效性核验、原能力保持、增强标签分配对照。此为建议，不声称本机已执行。

### 7.3 失败案例或机制诊断

- 任务失败按环境目标谓词，不用动作L1大小直接定义搜索任务失败。
- 风格分类与结果方差不是规划/控制层失败的完整因果机制分解。

### 7.4 例子走一遍（对照代码）

**⑥例子（2026-10-29）**：用户明确选择沿用论文“拿起可乐罐”。它对应论文SimplerEnv任务；按§V-A为3轮搜索，本节详看前2轮，第3轮按相同规则继续。此前8×7为OpenVLA-OFT/LIBERO接口示例，不据此指定本例SimplerEnv完整动作形状。

**演示合同**：保留论文批次5组×10、选1组10条、8个风格槽位；当前SimplerEnv代码n_evals=10。仅跟踪一个格子和其中一条候选，其他候选仍按正常流程处理但不逐条展示，避免另造一套容易混淆的批次数量。下列句子、Judge结果、成功次数与训练预测均为教学假设，不是作者真实搜索记录或本机实测。假设改写保持同一任务且专家示范适用，J不用于证明语义保持。

**场景**：桌上有一只可乐罐，任务为拿起它。原指令c0为“Pick Coke can”。

**第1轮：从原句生成A并入库**

1. archive为空时，从原始指令取改写起点；各候选可以有不同目标风格。
2. 生成5组×10个有效候选；按组内平均两两相似度选出一整组10条。源码ask中的best_idx=np.argmin(np.array(scores))、取list_of_final_outputs[best_idx]实现选组，不是已在此时选出8个代表。
3. 假设入选组包含A：“Hey, pick up that Coke can, please!”（请把那个可乐罐拿起来，口语表达）。
4. 固定基础VLA与A，10次完整任务评估使用任务允许的不同起始状态；假设8成2败。p=0.8，原式J=0.16，代码归一化4J=0.64。
5. 假设Judge将A归为z6口语格，且本轮该格最终由A胜出；该格由空变为A、0.64。其余格状态不展开，不能据本例认定仅该格填充或全部填满。

**第2轮：从A继续生成B并替换同格代表**

1. 假设随机抽中A作为参照，目标仍为口语风格。抽起点不会删除A；也不是固定抽第一个。
2. 重新生成5组×10，重新选一组10；其中有B：“Grab that Coke can, buddy!”（伙计，把那个可乐罐拿起来）。
3. 假设Judge也归z6；固定同一基础VLA，对B做10次完整任务评估，假设5成5败。p=0.5，J=0.25，4J=1.00。
4. 同格比较1.00>0.64，B替换A。分数变化来自候选文字改变，不是此时VLA被训练。库中其他格子不因z6替换而清空。

    z6：空 → 第1轮留下A（0.64）→ 第2轮留下B（1.00）
    取代表再改写 → 再评估 → 更新同一个库

第三轮仍按相同规则；达到论文轮数或当前配置预算后停，不把本节两轮展示当作完整论文实验运行。

**搜索后到监督训练：演示B如何使用**

假设B最终被列入训练用表述；另一条同任务改写C被留出评估。作者如何从最终8格/历史具体整理出10条清单仍未明确，本示例不补造这一规则。

另取已有正确专家示范D。D的t时刻画面、机器人状态和专家动作均保留，把部分训练示范的原始文字换为B：

    D中保存的画面/状态＋B
      → VLA预测动作
      → 与D中对应专家动作比较
      → 原模型训练损失
      → 更新VLA参数

只看某一维归一化动作的教学例：专家目标0.20、预测−0.10，该项绝对差0.30；这是一个分量的差，不冒充整动作块的平均loss。实际SFT沿用基座损失；本轮没有运行训练。搜索中B的5次失败动作不作为正确监督目标。

**训练后评估**

向微调后VLA输入原始指令，检查原能力；输入未参与训练的C，重复完整任务并统计成功率，与基础策略比较同任务新表述的鲁棒性。成功率是否提高必须实际测量，本示例不编造训练收益。

## 11. 对我的研究的迁移

### 11.1 可以直接继承

- **FACT（§III–IV）**：问题定义要求候选仍描述同一任务T；Q-DIG提供按风格组织候选、重复rollout评估、archive迭代搜索，以及用正确专家示范重标注微调的流程。

### 11.2 不能直接照搬

- **定义与验证分别判断**：Q-DIG并非允许任意改变任务，§III已要求候选属于描述同一T的指令集合；但生成要求、Sentence-BERT差异、风格分类、成功方差和human-likeness用户研究，分别支持不同性质，不能自动组合成全部候选逐条严格等价的证明（§IV-B、§V-A）。
- **与首篇人工审核的区别（2026-10-29回查原文）**：LIBERO-Para附录A.5（英文PDF第17页）随机抽取205对、约全量5%，由15名标注者判断给定场景下是否会引出相同成功行为；另在英文PDF第28页声明作者对全部生成改写作人工review/filter。两者分别为独立抽样语义评估与作者全量审阅，不能混同为全量独立标注。Q-DIG的40人用户研究（§V-A、§VI-A）评价human-likeness排名和评分，未报告前者这种抽样逐对语义有效性审核；不能将其概括为“完全没有人工评估”，也不能把自然度评价当作语义验证。
- **课题的工作性判据（待后续实验细化）**：固定同一场景，保留动作、对象、目标及已有执行约束，不额外增删要求；场景事实正确、指代合法和物理可执行另外核对。严格等价不要求复用相同词语，也不要求机器人每次走完全相同的轨迹；逻辑上等价的步骤展开仍可合格。
- **教学反例**：假设原句为“拿起可乐罐”，且场景中唯一可乐罐指代明确。“请把这罐可乐拿起来”通常可作等价候选；“慢慢拿起可乐罐”可能新增速度要求；“先把罐子推到桌边再拿起”可能新增路径/步骤约束；罐子并非红色时写“拿起红色可乐罐”引入虚假场景信息。后三者需要拒绝或专门核验，不能只凭最终目标仍为拿起判定严格保持。例句为教学构造，不是作者真实候选数据。
- **INFERENCE**：表I的副词、额外动作细节等风格尤其需要核验新增约束，但不能因此断言这些类别全部不合法，或整套Q-DIG数据均未保持任务。
- **指标边界**：高失败率/高方差不证明语义合法；任务失败也不自动证明达成攻击者指定的错误对象、轨迹或行为目标。

### 11.3 如何避免重复

- 已有贡献：多风格闭环搜索、能力边界方差目标、专家示范语言增强及未见表述评估；仅更换生成模型或风格名称不足以建立研究差异。
- **待核查的研究问题**：在逐条严格语义保持且场景有效的候选子集上，是否仍能稳定诱发VLA失效？若要求行为定向，还需单独定义并检验定向成功。
- **建议的最小区分**：分别报告候选合法率，以及合法候选内的行为失效率；生成器之外的独立核验可结合任务约束、人工复核与边界样例，而非仅让生成器自评。此为研究建议，尚未实施。
