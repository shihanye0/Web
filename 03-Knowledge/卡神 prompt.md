# 卡神的 12 个 Prompt

> 来源：[《都 Agent 时代了，我还是想分享给你这 12 个我最常用的 Prompt。》](https://mp.weixin.qq.com/s/NAdhdFrUq9-BKelqzqpwBQ)，数字生命卡兹克，2026-08-21。
>
> 使用时把 `【】` 替换为自己的信息；已有文档、数据或链接时一并提供。以下为便于复制的结构化整理版。

## 一、问清问题

### 1. 苏格拉底式问诊

```text
我的困惑是：【具体说明发生了什么、我的理解，以及卡在哪里】。

先不要给建议。请用苏格拉底式问诊，最多问我 6 个问题，帮我定位真正值得回答的问题。

规则：
1. 一次只问一个问题；根据我的回答决定下一问，不要预先给出问卷。
2. 区分可验证事实、对事实的解释、价值判断和我想实现的目标。
3. 检查含糊词、默认前提、证据来源、反向解释，以及结论成立或不成立的含义。
4. 每次提问前，用一句话说明上一条回答更新了什么判断。
5. 只问可能改变结论的问题；信息足够就停止，无须凑满 6 个。

结束后整理：
- 我最初的问题；真正想解决的问题；已确认事实；未验证假设；
- 最可能改变结论的变量；一个准确、具体、可继续行动的新问题。

等我确认新问题后，再给判断、理由与下一步行动。
```

## 二、学习

### 2. 双层解释法

```text
我想学习：【概念或问题】。

请分两层解释：
1. 小白版：用生活化语言和一个具体例子，让零基础读者听懂。
2. 专业版：使用准确术语，说明核心机制、适用边界和常见误解。

最后给出：
- 小白说法与专业术语的对应关系；
- 最容易误解的地方；
- 3 个用来检验我是否真正理解的问题。
```

### 3. 反向拆解优秀案例

```text
我要拆解的优秀范例是：【产品页面、网页、方案、流程、数据看板或其他成品】。
我想从中学会：【希望掌握的能力】。

先用一句话说明它解决了什么问题，再反向拆解其有效原因。重点分析：
1. 它服务谁，目标是什么；
2. 采用了什么结构或流程；
3. 哪些关键选择拉开了质量差距；
4. 它的完成标准；
5. 哪些规律可迁移，哪些细节只适合该案例。

最后输出：3 至 5 条可复用规律、一份可执行清单，以及一个最值得先做的小练习。
```

### 4. 横纵分析法（深度研究）

```text
研究对象：【产品、公司、人物、技术、行业或事件】。

请以执行当天为截止时间，完成一份可追溯的横纵分析深度研究。

纵向：说明诞生背景和推动者、关键转折及成败、早期选择如何形成今天的能力、路径依赖或包袱。
横向：选择最值得比较的对象并说明理由；按统一维度比较强项、短板和独特性；解释用户、客户或市场为何选择或放弃它。
综合：判断历史形成的能力与约束将怎样影响未来；给出最可能的 3 条路径，并列出各自前提与预警信号。

证据规则：优先使用官方资料、原始数据、论文、财报、访谈等一手来源；重要结论标注来源和日期；事实、推断、观点分开；冲突信息并列呈现；无证据时明确写“暂未核实”。

按“核心结论、关键时间线、横向对比表、详细分析、未来判断、待确认问题”的顺序输出。篇幅约 1 万至 3 万字，语言通俗且不堆砌资料。
```

### 5. 事实核查

```text
我要核查的说法是：【观点、结论、数据或方案】。

先拆分为：可外部验证的事实、从事实推出的结论、包含的价值判断。

对事实联网核查来源、样本、时间与完整上下文，并分别标记为：
已证实 / 基本成立但需收窄 / 有争议 / 证据不足 / 明显错误。

假设相关事实成立，再检查：
1. 事实是否足以推出当前结论；
2. 是否夹带未验证假设；
3. 是否混淆相关与因果；
4. 是否遗漏其他解释或关键信息；
5. 结论在什么条件下成立或失效。

最后给出：可信与待修正的事实、推理链最关键的漏洞、补强后的合理版本、目前可相信到什么程度。
```

## 三、解决问题

### 6. 专家会诊

```text
我的问题是：【问题、已知事实、目标与现实约束】。

先不要直接给方案。请选择 3 种真正互补的专业视角，并说明每种为何必要。

让每种视角分别说明：如何重述问题、最推荐路径、其他视角容易忽略的风险、什么新证据会令它改变判断。

随后让三种视角相互质疑，找出共同认可的事实、真正分歧及分歧背后的假设。

最后输出：最推荐的综合方案、适用条件、最大风险、退出条件和第一步行动。
不要选择高度相似的身份，也不要模仿或编造真实人物观点。信息不足时，只问我一个最关键的问题。
```

### 7. 第一性原理

```text
我想解决的问题是：【问题】。

请用第一性原理把它拆到底层，明确：
1. 已确认且无法绕开的基本事实；
2. 习惯接受但未验证的假设；
3. 真正要实现的目标；
4. 现实资源与约束。

暂时放下行业惯例和现成方案，只从事实、目标和约束重新推导可行路径。

最后输出：原方案中只是修补表面的部分、重新推导出的路径、该路径的成立前提、验证它的第一步。
```

### 8. 跨领域借解

```text
我的困惑是：【背景、当前做法、现实约束与具体卡点】。

先去掉行业术语，把它抽象为其他领域也会遇到的人类问题，并识别：
问题的底层结构、真正矛盾、普通解法为何失效。

再从历史案例和至少 3 个彼此距离较远的领域中，寻找结构相似的问题。每个案例说明：
- 当时的问题与解决机制；
- 与我问题的相似处；
- 可迁移的部分；
- 会失效的条件。

最后选出最值得借用的 3 种机制，翻译成适合我处境的方案，并推荐一个低成本、可逆、最值得先试的实验。
```

## 四、决策

### 9. 双向钢人论证

```text
我需要做的决定是：【决策问题、两个选项、目标与现实约束】。

先不要给结论，也不要默认问题已经想清楚。请做一次双向钢人论证：
1. 用最完整、有力的方式重述我真正需要做出的选择；
2. 分别写出两边最强理由、适用条件、最大收益、最大风险和最难回应的反对意见；
3. 找出真正分歧、最可能改变结论的变量和仍需补充的信息；
4. 只问我一个最可能改变结论的问题。

等我回答后，再给明确判断、理由、适用条件与下一步行动。
```

### 10. 用最小实验替代空想

```text
我正在纠结：【选择或想法】。

先找出决定背后最需要验证的 3 个假设，再选出最可能改变结论的一个。

围绕它设计一个低成本、可逆、能在【7 天或可接受周期】内完成的最小实验。请写清：
1. 具体动作；
2. 时间与资源投入；
3. 观察指标；
4. 什么结果支持继续；
5. 什么结果意味着停止；
6. 实验结束能获得什么新信息。

最后告诉我明天就能开始的第一个动作。
```

## 五、认识自己

### 11. 挖掘隐藏天赋

```text
# 角色：深度天赋挖掘机

你是一位了解优势识别、心流理论与荣格心理学的生涯咨询师。请把天赋视为可迁移的底层能力，并留意它可能藏在怪癖、被批评的特征、嫉妒、无意识胜任区与能量模式中。

目标：通过多轮对话，识别被忽视或压抑的天赋，最后写出一份有证据、专业且有共情力的《个人天赋使用说明书》。

对话规则：
1. 每次只问一个问题，遵循“提问 -> 用户回答 -> 简短反馈 -> 下一问”。
2. 多追问年龄、具体事件、感受和行动，避免根据一句话贴标签。
3. 温暖而敏锐；可以指出矛盾或潜在线索，但不要空泛安慰。
4. 所有判断对应用户讲过的经历；证据不足时使用“可能”，并继续追问。
5. 最多 10 个主问题，覆盖以下主线：
   - 16 岁前主动投入的事，以及反复被批评却改不掉的特征；
   - 成年后“这还需要学吗”的无意识胜任区；
   - 做完后精神亢奋与明显耗竭的事情；
   - 强烈羡慕的人或生活，以及真正渴望的部分。

信息足够后，输出约一万字的《个人天赋使用说明书》，包括：有经历链支撑的底层天赋、天赋的阴影面、能量地图与高消耗区、适合与不适合发挥的环境、工作与合作方式及现实限制、未来 30 天的低成本验证实验。

先用温暖、专业、通俗的语言说明流程、预计时间与目标，然后进入第一个问题。
```

### 12. 人生设计术

```text
# 角色：人生设计师

你熟悉斯坦福人生设计方法、心流理论与积极心理学。请陪我把当前人生当作可反复设计、低成本试错的项目：先看清位置，再找到方向，再把可能的路试出来。

目标：通过多轮深度对话，区分无法直接改变的重力问题与可设计的问题，最终给出 3 个完全不同但都值得认真考虑的五年版本，以及能立刻启动的原型行动，形成《个人人生设计蓝图》。

原则：人生没有唯一正确答案；重新定义问题优先于急于回答；识别并接纳重力问题；足够多的选择带来质量；热爱常在行动与反馈后出现；原型即便失败也会留下信息。

对话规则：一次只问一个问题，给出简短而真诚的反馈再继续；追问具体事件、感受和行动；指出逻辑漏洞、自我设限与言行落差；不替我做决定；主问题控制在 6 至 9 个。

依次覆盖：
1. 当前位置：健康、工作、娱乐、爱四项各打 0 至 10 分，找出红灯；把焦虑的问题区分为重力问题或可设计问题。状态稳定且征得同意后，可用“维持现状五年/十年”的反向推演；情绪脆弱时跳过。
2. 指南针：澄清工作观、人生观及其一致性。
3. 寻路：回顾心流时刻，区分回血、耗竭和“擅长但不热爱”的事。
4. 创造可能：找出失效却不愿放手的执念；生成三个都是真心愿意考虑的五年 A 计划：当前/常想的路、第一条路消失后的路、不考虑金钱和评价时的路。

材料足够后输出 8000 至 12000 字《个人人生设计蓝图》，包括：四项仪表盘、重新定义后的真问题、指南针、能量地图、三个奥德赛计划（标题、五年时间线、待验证问题、资源/喜欢程度/自信心/一致性评估）、倾向路径的季度问题与一个月原型、人生对谈/短期体验/本周第一步，以及“失败免疫”提醒。

先温暖开场，说明方法、预计时间与目标，再进入第一个问题。
```

## 使用索引

| 需求 | 优先使用 |
| --- | --- |
| 还没想清楚自己真正的问题 | 苏格拉底式问诊 |
| 听懂概念但不理解机制 | 双层解释法 |
| 学习一个优秀作品 | 反向拆解 |
| 系统研究陌生对象 | 横纵分析法 |
| 判断信息、数据或观点是否可靠 | 事实核查 |
| 问题牵涉多种专业能力 | 专家会诊 |
| 现有方案陷入补丁和路径依赖 | 第一性原理 |
| 本行业找不到突破口 | 跨领域借解 |
| 两个方向都很有道理 | 双向钢人论证 |
| 决策需要现实反馈 | 最小实验 |
| 想识别优势与能量模式 | 挖掘隐藏天赋 |
| 想探索未来的人生路径 | 人生设计术 |
