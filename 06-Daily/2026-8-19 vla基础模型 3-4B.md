### 1. 不是简单地“把原 7D head 删掉，新建 24D head”

官方 custom config 当前确实是：

```yaml
action_model:
    action_dim: 7
    future_action_window_size: 15

fm_head_config:
    action_dim: 7
    action_horizon: 16

vla_data:
    action_type: delta_ee
```

也就是说公开路线默认是 **7D delta EEF**，并不是你的 **24D absolute joint**。([GitHub](https://github.com/InternRobotics/InternVLA-M1/blob/InternVLA-M1/InternVLA/config/training/internvla_cotrain_custom.yaml "InternVLA-M1/InternVLA/config/training/internvla_cotrain_custom.yaml at InternVLA-M1 · InternRobotics/InternVLA-M1 · GitHub"))

但是代码本身把 `action_dim` 做成了配置参数，而且整个 M1 forward 接受的是：

```text
action: [T, action_dim]
```

推理同样输出：

```text
[B, T, action_dim]
```

所以从架构上看，**24D 是能接进去的，并不是整个 InternVLA-M1 天生只能做 7D**。([GitHub](https://github.com/InternRobotics/InternVLA-M1/blob/InternVLA-M1/InternVLA/model/framework/M1.py "InternVLA-M1/InternVLA/model/framework/M1.py at InternVLA-M1 · InternRobotics/InternVLA-M1 · GitHub"))

因此我更推荐：

```text
不要：
7D DiT action head
        ↓
整个删除
        ↓
随机初始化全新的 24D action head
```

而是：

```text
预训练 InternVLA-M1

Qwen2.5-VL     保留
DINO           保留
QFormer        保留
DiT backbone   尽量保留
     │
     ├─ 7D action encoder   → 改成 24D
     │
     └─ 7D action decoder   → 改成 24D
```

也就是**只重新初始化与 action dimension 直接相关的输入/输出投影，尽量保留中间 DiT diffusion blocks 的预训练能力**。

这比“新建整个 24D head”更合理。

### 2. 比 7D→24D 更大的问题其实是：**当前官方 M1 没明显使用 proprioception / joint state**

这个对你的 P247 很重要。

我检查了当前 `M1.py`。官方 forward 明确取：

```python
batch_images
instructions
actions
```

然后：

```text
Qwen视觉/语言
       +
DINO视觉
       ↓
QFormer
       ↓
action_condition
       ↓
DiT
```

action 是训练标签，但在这条公开的 action-conditioning 路径里，我没有看到当前 `qpos / proprio / state` 被作为条件输入；源码里也没有找到 `state`、`proprio` 或 `qpos` 对应的 conditioning。([GitHub](https://github.com/InternRobotics/InternVLA-M1/blob/InternVLA-M1/InternVLA/model/framework/M1.py "InternVLA-M1/InternVLA/model/framework/M1.py at InternVLA-M1 · InternRobotics/InternVLA-M1 · GitHub"))

而你的数据实际上有：

```text
RGB
+
24D 当前关节状态 q_t
+
24D action target
```

对于 G1 双臂+双手控制，我认为 **q_t 很有价值**。

比如机器人看到完全一样的画面：

```text
药盒在同一个位置
```

但当前机器人可能分别处于：

```text
情况 A：
左肩 = 0.15 rad
左肘 = 0.72 rad

情况 B：
左肩 = 0.35 rad
左肘 = 1.02 rad
```

如果输出的是 joint-space action，模型最好知道**机器人当前关节到底在哪里**。

所以 InternVLA-M1 真正需要你额外审计的，不只是：

```text
7D → 24D
```

而是：

```text
视觉 + language
        +
      24D q_t
        ↓
   action expert
        ↓
24D joint target
```

## InternVLA-M1 最大的价值其实不是“第四个又能控制机器人的 VLA”

它和你前三个模型形成的组合非常好：

```text
GR00T N1.7
    ↓
标准机器人 foundation policy
joint-space 接入最干净

Psi0
    ↓
G1 / humanoid 主线
action expert 路线

HEX
    ↓
humanoid specialist
验证 delta joint policy

InternVLA-M1
    ↓
spatially-guided VLA
验证“空间理解能力”到底能不能提高抓取/倾倒
```

InternVLA-M1 官方的核心卖点恰恰就是 **spatial grounding → action**。论文采用先做空间 grounding，再用 spatial prompt 指导 action post-training 的路线；官方报告里，加入 spatial guidance 相比去掉它的版本，在多个机器人 benchmark 上都有明显提升。([arXiv](https://arxiv.org/abs/2510.13778?utm_source=chatgpt.com "InternVLA-M1: A Spatially Guided Vision-Language-Action Framework for Generalist Robot Policy"))

这非常适合你这种任务：

```text
找粉色药盒
      ↓
判断药盒位置
      ↓
抓取
      ↓
找到橙色药杯
      ↓
移动到杯子上方
      ↓
倾倒
```

特别是以后你开始随机化：

```text
药盒位置变化
杯子位置变化
相机视角变化
桌面布局变化
```

InternVLA-M1 的价值会比现在固定场景明显得多。这是我认为它值得作为第四模型的主要原因。官方自己公布的结果中，InternVLA-M1 在 WidowX、Google Robot 和 LIBERO 上都表现很强，但这些数字属于作者自己的 benchmark，不能直接等价成你的 G1 成功率。([GitHub](https://github.com/InternRobotics/InternVLA-M1 "GitHub - InternRobotics/InternVLA-M1: InternVLA-M1: A Spatially Guided Vision-Language-Action Framework for Generalist Robot Policy · GitHub"))

### 所以我会把你原来的描述改成

> **InternVLA-M1**
> 
> 保留为第四模型，定位为 **spatial-grounding / spatial-generalization baseline**。  
> 使用官方 Qwen2.5-VL + DINO + Layer-QFormer + DiT 架构。  
> 将官方默认 `7D delta_ee` action contract 改为 **24D joint-space action contract**；不简单丢弃整个预训练 DiT action expert，而是优先仅替换/扩展与 7D action dimensionality 绑定的输入输出层。  
> 第一轮冻结 Qwen2.5-VL 与 DINO，训练 QFormer / state interface / action expert。  
> **建议新增 24D current joint-state conditioning**，否则它与 GR00T/Psi0/HEX 的 proprioceptive policy 对比并不完全公平。  
> 第一轮保持 RGB-only；等 24D baseline 跑通后，再考虑深度/3D spatial input。

最终优先级我会定成：

**Psi0 ≈ GR00T N1.7 > HEX > InternVLA-M1**

但如果你的研究重点后面从“固定场景把任务做成功”转向**“药盒和药杯随机摆放还能成功”**，那 InternVLA-M1 的优先级甚至可以超过 HEX。
