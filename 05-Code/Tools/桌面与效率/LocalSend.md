# LocalSend

开源跨设备局域网互传工具（AirDrop 的全平台开源替代）。本机版本 **1.18.2**（winget，2026-09-12）。

## 它解决什么

同一 Wi-Fi 下手机↔电脑直接互传文件、照片、甚至文本/剪贴板内容——不经过任何云服务器，速度快、无隐私顾虑、无文件大小限制。

## 如何使用

1. 电脑和手机都装 LocalSend（手机端在应用商店或官网下载）。
2. 两端连同一网络后自动互相发现（无需登录账号）。
3. 选设备 → 发送 → 对方确认接收。也可生成链接/二维码接收。

## 适用场景

- 手机拍的实验照片/白板照片传电脑
- 电脑里整理好的文献 PDF 传手机通勤看
- 替代"微信文件传输助手"，尤其是不方便登录微信的机房环境

## 搭配

- 传到电脑的照片 → [[Umi-OCR]] 识别白板文字 → Obsidian 会议笔记
- 大文件场景比微信/网盘快一个数量级，且不压缩画质
