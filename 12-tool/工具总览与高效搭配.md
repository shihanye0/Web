## 二、四条核心工作流

### 1. 论文阅读流水线（最重要）

```text
新论文 → Zotero 00_Inbox（[[Zotero 插件清单]]：划词用 Translate for Zotero）
              ↓
   扫描件？──是──→ [[Umi-OCR]] 转可搜索 PDF
              ↓ 否
   需要整篇中文对照？──是──→ [[pdf2zh]]
              ↓ 否
   复杂双栏/公式表格？──是──→ MinerU（E:\论文\科研AI工具 wrapper）
              ↓
   单篇深读 → Obsidian 笔记模板（见 [[VLA科研工具与论文阅读工作流]] 第 5 节）
              ↓
   跨文献提问 → 深度用 PaperQA2（联网、付费、证据密度高）
                日常速查用 [[AnythingLLM]]（本地、免费、随时问）
```

**分工原则**：PaperQA2 做"关键结论的证据综合"（值得花钱），AnythingLLM 做"已读文献的日常速查与隐私文档问答"（零成本、离线）。两者都只是助手，结论必须回原文核对。

### 2. 组会 / 讲座记录

```text
录音（腾讯会议/手机）→ [[whisper-ctranslate2]] 转写 → Obsidian 会议笔记
```

### 3. 日常操作肌肉记忆

- `Alt+Space` 呼出 [[Flow Launcher]]，从这里启动一切（PowerToys Run 默认未启用，无按键冲突）
- 资源管理器选中文件按 `空格` 预览（[[QuickLook]]）
- `Win+Shift+T` 屏幕取词（[[PowerToys]]）；中文扫描件交给 [[Umi-OCR]]
- `Win+V` 系统自带剪贴板历史（已有 EcoPaste 则二选一）
- 手机传文件用 [[LocalSend]]，不再走微信

### 4. 每周维护（5 分钟）

打开 [[UniGetUI]] → 全选更新 → 完成。所有 winget 软件一次性升级，不再逐个弹窗。

## 三、安装与升级约定

- **桌面软件**：winget 安装（`winget install <id>`），升级统一走 [[UniGetUI]]
- **Python 命令行工具**：一律 `uv tool install <包名>`（隔离环境，不污染 conda）
- **大体积软件装 E 盘**（C 盘只留系统）
- GitHub 下载走镜像前缀；FlClash 开启时 winget 通道正常
