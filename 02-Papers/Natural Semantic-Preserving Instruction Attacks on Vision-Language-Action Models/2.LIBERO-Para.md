什么叫做二元成功率（Binary success rate）

在 VLA 研究中，可以简单理解为：
> 模型不仅要理解文字的含义，还要把文字中的概念正确对应到真实或仿真环境中的物体、动作以及任务目标。
> 把语言中的语义与环境中的实体和行为建立联系。

| 对比         | 表层匹配             | 语义扎根           |     |
| ---------- | ---------------- | -------------- | --- |
| 理解方式       | 依赖训练时见过的关键词、表达模式 | 根据语义和场景确定对象与行为 |     |
| 看到 `stove` | 匹配熟悉的物体名称        | 定位场景中的炉灶       |     |
| 换成 `range` | 可能无法正确匹配         | 仍能定位同一个炉灶      |     |
| 主要问题       | 容易对固定措辞过拟合       | 对同义表达通常更稳健     |     |

模型很可能学到了训练指令与动作之间的固定关联，却没有充分建立对物体概念的稳健理解。

二元成功率：Binary Success Rate 是通过“成功记 1，失败记 0”计算任务完成比例的一种指标。

作者认为的问题是：以前的一些工作虽然也测试语言改写，但语言改写只是整个测试体系的一部分，没有针对“保持语义不变的语言改写”进行足够精细的分类和分析。

作者认为，有些研究没有严格区分“换一种说法”和“换一个任务”。
情况 A：语义不变
Original: Put the bowl on the stove.
Paraphrase: Place the bowl on the cooktop.
两条指令在当前场景中都要求：把同一个碗放到同一个炉灶上。
目标物体不变，最终任务不变

情况 B：语义发生改变
Original: Put the bowl on the stove.
Changed: Put the plate on the stove.
第一条要求放碗，第二条要求放盘子，任务目标已经改变。
目标物体发生变化，已经是不同任务

因此作者认为它将任务语义变化与语言表达变化混在了一起。
对你研究的 VLA 攻击而言，这个区分尤其重要：攻击成立的关键不是让模型执行另一条指令，而是在用户任务没有改变的情况下，让模型偏离原本任务。

显式建模：研究者是否明确把机器人指令拆解成不同的语言组成部分，并按照这些部分设计、分类和分析改写实验。
作者将改写重点分成两个轴（Axis）：
Action Axis：动作表达变化
例如：
- `Put` → `Place`：动词替换。

- `Put the bowl...` → `Carefully put the bowl...`：增加修饰词。
    
- `Could you put the bowl...`：改成委婉疑问句。
    

Object Axis：物体指称变化

例如：

- `stove` → `cooktop`
    
- `bowl` → `container`
    
- `stove` → `gas stove`
    

随后还可以进行组合：

`Put the bowl on the stove.`

改成：

`Could you place the container on the cooktop?`

这样就能单独研究动作改写、物体改写，以及两者组合产生的影响。
