# pdf2zh

PDFMathTranslate——开源学术 PDF 翻译工具（EMNLP 2025 Demo 论文）。本机版本 **1.9.11**（`uv tool install pdf2zh`，2026-09-12）。

## 它解决什么

把英文论文整篇翻译成**保留原始排版**的中文版：公式、图表、表格、目录、超链接的位置都不动，只把文字换掉。支持生成"双语对照"版，逐段上下对照着读。

## 如何使用

```powershell
# 最简用法：在论文所在目录执行
pdf2zh paper.pdf
```

- 默认在当前目录生成**翻译单语版**和**双语对照版**两个 PDF
- 翻译服务、目标语言等参数较多，执行 `pdf2zh --help` 查看全部选项
- 首次使用前建议先拿一篇短文献试跑，确认所选翻译服务的质量与额度

## 适用场景

- **精读**一篇重要文献时做中文对照（粗筛不需要，浪费额度）
- 组会上要给同学讲解的英文论文，提前转成对照版
- 公式密集的 ML/机器人论文——这是它相对普通"PDF 翻译器"的核心优势

## 搭配

- 在 [[Zotero 插件清单]] 里可通过插件市场安装 **zotero-pdf2zh** 插件，右键条目直接翻译；命令行版则适合批量处理
- 翻译版用于人读；要喂给知识库做问答时不必翻译，直接用原文（[[AnythingLLM]] 的嵌入检索对英文原文效果更好，译文只留给"人"）
- 排版复杂的论文翻译完先抽查公式和图表是否错位，再决定是否采用

## 注意

- 翻译质量依赖所选服务；部分服务需要联网或有额度限制
- 与 MinerU 的分工：**pdf2zh 给人读，MinerU 给机器读**（结构化提取），不要混用输出
