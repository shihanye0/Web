# Flow Launcher

开源键盘启动器。本机版本 **2.1.3**（winget，2026-09-12）。

## 它解决什么

把手从鼠标上解放出来：按 `Alt+Space` 呼出输入框，直接打字完成启动程序、搜文件、算数、翻译、剪贴板历史等操作，不用在开始菜单和文件夹之间点来点去。

## 如何使用

1. 默认快捷键 `Alt+Space` 呼出（本机 PowerToys Run 默认未启用，无冲突，直接可用）。
2. 基本玩法：
   - 直接输入程序名 → 回车启动
   - `>` 开头搜文件；`=` 开头做计算
   - 输入关键词即搜，方向键选择，回车打开
3. 插件生态（设置 → 插件商店）：建议装"翻译"类和"剪贴板"类插件补足日常动作；中文社区插件丰富。

## 适用场景

- 快速启动不常驻任务栏的软件（DevToys、Umi-OCR、draw.io……）
- 写作中随手算个损失值、换算单位
- 找文件记不清全名时模糊搜索（比资源管理器搜索快得多）

## 搭配

- 与 [[QuickLook]] 组合：Flow Launcher 找到文件 → 回车前先想想内容，可改用资源管理器+空格预览。
- 与 [[开发效率小件]] 的 fzf 分工：Flow Launcher 管图形界面世界，fzf 管终端世界。
