# Ollama 本地模型

本地大模型运行时。本机版本 **Ollama 0.24.0**，已拉取模型 **qwen3:4b**（2.5 GB，2026-09-12）。

## 本机性能实测（RTX 3050 Laptop 4G 显存）

- 生成速度 **39.57 tokens/s**，显存占用 **3780/4096 MiB**——模型几乎完全驻留 GPU，速度可用
- 结论：**3~4B 量化模型是 4G 显存的甜点位**；7B 模型会溢出到内存，速度明显下降，不建议
- 首次加载约需几十秒（读盘进显存），之后热加载很快

## 常用命令

```powershell
ollama run qwen3:4b          # 进入对话（--think=false 可关掉思考过程标签）
ollama list                  # 已装模型
ollama ps                    # 当前加载情况（看是否占用 GPU）
ollama pull <模型名>         # 拉取新模型
ollama rm <模型名>           # 删除模型释放空间
```

qwen3 的回答默认带 `<think>…</think>` 思考段，命令行加 `--think=false`，在 [[AnythingLLM]] 里不影响使用。

## 模型选择原则（4G 显存）

| 需求 | 选择 |
| --- | --- |
| 日常问答/文献速查（当前） | qwen3:4b ✓ |
| 更强推理 | 显存不够，走云端（PaperQA2 / ChatGPT） |
| 轻量备用 | gemma3:4b 同档可换着试 |

## 适用场景

- 作为 [[AnythingLLM]] 的推理后端（已接好）
- 离线环境下的临时问答、文本润色、代码小助手
- 不想敏感内容出本机的任何 LLM 需求

## 注意

- 开机自启默认开启；长期不用可在任务管理器禁用，用时再开
- 显存被 NVIDIA Broadcast 等占用时模型可能部分落回内存，速度下降——重度推理前先关掉占显存的软件
