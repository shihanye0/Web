****课题名称：面向vla模型的语义保持型自然指令攻击研究**

核心问题：在**不改变原始任务目标、不引入虚假场景信息、保持指令自然可理解**的条件下，通过不同的语言表达方式，使 VLA 模型产生显著的行为偏移、任务失败或定向错误行为。**
而你可以把重点明确放在：

\[Natural} + \{Semantic-Preserving} + {Scene-Valid} + {Behaviorally Effective} \]
{语义不变} + 自然合法} + \{主动攻击} + \{行为有效} \]
这四个条件同时满足。

而是按“先搞清问题，再学攻击，再看定向行为，再补机制”的顺序。

最推荐的顺序是：

1. **LIBERO-Para**  
    先看它，因为它最适合建立你的问题定义。重点看：什么叫 paraphrase、怎样保证任务语义不变、哪些改写最容易导致失败、失败发生在规划还是执行阶段。  
    你读完后要能回答一句话：**“仅仅换一种正常说法，VLA 为什么会掉点？”**
    
2. **Q-DIG**  
    第二篇看，因为它已经从“被动测试 paraphrase”走到了“主动搜索会让 VLA 失败的自然指令”。重点看：候选指令怎么生成、如何保持 task-relevant、naturalness 怎么评估、攻击搜索怎么做。  
    你要重点找它的边界：**它的 natural 是否等于我们想要的“严格语义保持”？**
    
3. **Trajectory-Level Redirection Attacks on VLA Models**  
    第三篇非常关键。它把目标从“让任务失败”提升到“让行为/轨迹朝攻击者指定方向偏移”。重点看 closed-loop rollout、targeted objective、trajectory divergence、攻击成功定义。  
    你要学的是：**如何从 failure attack 升级成 behavioral redirection**，但不要照搬它的 typo/字符扰动。
    
4. **SABER**  
    第四篇看黑盒攻击方法。重点不是自然语言定义，而是：不知道模型梯度时，怎么根据 rollout 结果不断搜索更有效的攻击指令；reward 怎么写；query cost 怎么衡量。  
    这篇对你以后设计“自动攻击器”最有用。
    
5. **RoboGCG**  
    第五篇补历史和攻击基础。重点理解 VLA attack 与普通 LLM jailbreak 的区别：攻击结果最终作用在 **action space / trajectory**，不是文本输出。  
    不必一开始深挖它的优化细节。
    
6. **Embodied Red Teaming for Auditing Robotic Foundation Models**  
    第六篇看整个方向最早期的思想：为什么机器人 foundation model 需要 red teaming、为什么自然语言表达覆盖不全会成为问题、如何生成 context-grounded challenging instructions。
    
7. **Grounded Semantic Re-Binding / 类似 paraphrase robustness defense 工作**  
    放后面看。重点研究：**为什么模型明明“理解”了相同任务，动作却变了**。这对你以后做机制分析和 defense 很重要。
    
8. **AttackVLA + VLA Attack Survey**  
    最后看，用来查漏补缺和写 Related Work，不需要最先精读。
    

所以你现在真正应该精读的前四篇就是：

**LIBERO-Para → Q-DIG → Trajectory Redirection → SABER**

对应关系也很清楚：

**LIBERO-Para：问题是否存在**  
→ **Q-DIG：怎样自动找到自然失败指令**  
→ **Trajectory Redirection：怎样让行为定向偏移**  
→ **SABER：怎样做黑盒自动搜索**
