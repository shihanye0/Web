# 开发效率小件

一批装机即用的小工具合集（2026-09-12 winget 安装，**新开终端后生效**）。

## fzf —— 模糊搜索器

| 场景 | 用法 |
| --- | --- |
| 翻历史命令 | `Ctrl+R`（比默认的逐条翻好用十倍） |
| 模糊找文件 | `Ctrl+T`（Git Bash / PowerShell 插件环境） |
| 管道模糊过滤 | `history | fzf`、`git branch | fzf` |

任何列表输出接一个 `| fzf` 就变成交互式筛选。

## lazygit —— 终端 Git 界面

仓库目录下输入 `lazygit`：分支、暂存、提交、rebase、冲突解决全部键盘可视化操作。适合不想记复杂 git 命令、又嫌 GUI 笨重的场景。

## DevToys 2.0.9 —— 开发者瑞士军刀

离线小工具集：JSON 格式化、正则测试、Base64/URL 编解码、时间戳转换、Hash 计算等。调试接口、处理日志、验签名时不用再开在线工具站。

## yt-dlp —— 视频/音频下载（已升级到最新）

```powershell
yt-dlp "<视频或播放列表 URL>"          # 基本下载
yt-dlp -f "bv*+ba/b" "<URL>"          # 最佳画质+音质合并
yt-dlp -x --audio-format mp3 "<URL>"  # 只抽音频
```

配合既有下载习惯（B 站缓存、抖音内容），替代过期旧版（旧版 2024.10 常因站点改版失效，**保持更新**——升级走 [[UniGetUI]]）。

## 7-Zip 26.03 —— 压缩/解压命令行

```powershell
7z x archive.zip -oE:\output    # 解压到指定目录
7z a out.7z 文件夹               # 打包
```

GUI 右键菜单同样可用；脚本里处理压缩包不再依赖第三方网站。

## 搭配

- fzf + lazygit 是终端里的"拇指流"组合：找分支、挑文件、翻提交全程不离键盘
- DevToys 与 [[Flow Launcher]] 组合：呼出启动器直接进对应工具
- 下载的文献/数据包 → 7-Zip 解压 → 进 [[AnythingLLM]] 或 Obsidian
